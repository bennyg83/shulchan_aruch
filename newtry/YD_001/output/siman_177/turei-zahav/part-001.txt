It appears Rambam, mara de'atra, per Gemara: if half in wages, two-thirds in loss; if half in loss, two-thirds in wages; Rashi: first clause on giver, second on recipient; Rambam all on recipient — if stipulated half in wages and not in loss, he bears two-thirds of loss calculated as if that loss were profit share; example loss 24 — if profit he would take 12, now bears 8; proportionally e.g. quarter wages — if damage, recipient bears two-thirds (4); if three parts wages and giver quarter, damage on recipient 12. If half loss stipulated without profit clause — two-thirds in wages: if profit 24 he takes 16; not from sum as if loss like first clause. If quarter loss on recipient without profit clause — two-thirds in wages: calculate as if giver would bear three-quarters of hypothetical loss 18, recipient takes two-thirds of 18 = 12. Main girsa not "takes a third" — Ramban follows recipient's share always; Rambam rejects — recipient should not take only 8 and giver 16.
