<small>(שם)</small> הכא הפסול בגופי'. דכיון שהוא עצמו נפסל נתבטל עשיה והו' כאלו מעולם לא נעשה בהכשר וכ"ז נתבאר בס"ד בסי' ט"ו:
**** ENGLISH ****
<small>Ibid.</small> Here the invalidity affects the object itself. Since it itself became invalid, the original act is nullified and it is as though it had never been made validly. All this was explained, with Hashem's help, in siman 15.

<small>(שם)</small> וכ"מ סי' י' ס"ו. דשם מבואר לשיט' רמב"ם בנתכוון להוסיף אי חתך בתראי לא מיתכשרי בקמאי אע"ג דנעשו התחל' בהכשר והיינו משום דבל תוסיף הוי פסולו בגופו ועיין מה שכתבתי בס"ד בסי' י"ב אות ד' יש קצת סתירה לכאן ויש ליישב ודוק:
**** ENGLISH ****
<small>Ibid.</small> The same is implied by siman 10, seif 6. There it is explained that according to Rambam, if one intended to add an additional set of tzitzis and afterward cut away the latter set, the first set does not become valid, although it was originally made validly. This is because the prohibition of adding is an invalidity in the object itself. See what I wrote, with Hashem's help, in siman 12, letter 4. There is a slight contradiction to this passage, but it can be resolved. Examine this carefully.
