2) Some say that this rule, that even in another script it is valid, applies specifically when it is also written in another language. But if he writes it in the Holy Tongue, he must write it specifically in Ashuris script, and if he wrote the language in the Holy Tongue but the script is not Ashuris, it is invalid. This is the Radbaz in Leshonos HaRambam, siman 126, and Beis Oved, os 17, wrote similarly in the name of Chasdei David. But Maran in Beis Yosef rejected this view and wrote that we are particular only that it not be written in another language, so that it should not be like one reading by heart; but whenever it is written in that language, even if it is written in another script, we have no problem with it. Beis Oved wrote there that the view of Maran is primary.
