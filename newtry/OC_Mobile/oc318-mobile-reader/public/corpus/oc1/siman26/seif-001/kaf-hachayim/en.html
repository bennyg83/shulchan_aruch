(1) [Se'if 1] Only one tefillah — don what he has, etc. Same if has both but constraint — one fulfills that mitzvah; forbidden lechatchilah head before arm or to cancel without onus (Beit Yosef). Maharil Molcho (Jerusalem teshuvah 85) — forgot head before arm — need not remove, fulfilled mitzvah (Birkhei Yosef 1; Taz 482:4). Not like Avudraham — "me'akevot" implies wrong order invalid; that gemara not in Bavli (Yerushalmi Ma'aser Sheni 5:5 — dispute if head before arm; Penei Moshe explains vidui vs. parashah). Taz from Avudraham — not gemara itself; per Penei Moshe — not whether yotzei but cannot say "all mitzvot" if reversed at first wearing. Orach Rachamim 484:3; Avodat Rachamim 484:2 — head first, no removal; Peri Megadim; She'elat Ya'avetz 125; not Hilkat Tachton 53; Birkhei Yosef 25:3; Kesher Godel 3:3; Chida; Zecher LeChaim; Siddur Beit Yosef 25; Sha'arei Tefillah 25:13 — got arm later; Leket Yosef — no removal. Ari (Sha'ar HaKavanot) — order before donning; if already reversed — need not remove, order passed; spiritual residue remains (Chida). If not yet tightened properly — remove, arm then head. See above 25:41, 46.
