(s.k. 6) However, etc. This refers to grain that has sprouted; for regarding what a mouse ate, one does not need sixty, as is written in s.k. 5 in the name of the Rashba. For if there is not sixty there, it is forbidden to add until there is sixty, since that would be like nullifying a prohibition; it is enough if we permit when there is already sixty. And see there in Magen Avraham; and the Peri Chadash is stringent even if there is already sixty: even though his intent is not to nullify, nevertheless it is like nullifying a prohibition, for he could separate it; see there.
