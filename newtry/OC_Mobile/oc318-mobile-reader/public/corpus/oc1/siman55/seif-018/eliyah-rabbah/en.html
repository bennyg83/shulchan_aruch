They do not, etc. For there is a partition, and the doorway is like a partition. The same applies to a large courtyard and a small one when it was not breached, as Rabbeinu Yerucham wrote on page 28. The wording of the Perishah is: because there is a partition and a door that can be closed, and it is considered as if closed. What is written in seif 20, that an idol interrupts, is explained in the Beit Yosef in the name of the Yerushalmi, which wrote that a Kusi interrupts. Thus an idol is like the idolaters themselves, unlike the Magen Avraham, seif katan 15.
