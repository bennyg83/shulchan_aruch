Seif 3, if he began, etc. See the Magen Avraham, whose intent is the entire Shemoneh Esrei, as written in the Yerushalmi cited above. It says even Kedushah to teach that it is not an independent matter. The proof is that the Mishnah there does not count it separately, but it is included in one does not pass before the ark; see the Rashba, siman 96. The same applies to Kaddish, as written in the gloss.
And if they left, etc. But one does not, etc. As above from the Yerushalmi, for each matter is independent. This is also what is meant by the evening prayer, etc.
And Kedushah. This is not precise; see the Magen Avraham.
