Things that invalidate tzitzis — it contains three clauses.
If all the strings of the corner tore but enough remained to tie all the torn strings together, it is valid; if there did not remain enough to tie — even for one string that tore entirely — it is invalid. Therefore since each [strand] is folded to two, if two ends tore it is invalid lest one string tore entirely. According to our practice at making tzitzis to mark [such that] the four ends are always on one side of the knot and four ends on the other — if two ends on one side tore it is valid, for surely they are two strings and more than kedei aniva remains from the second end of each. Rabbenu Tam validates only if two complete strings remain — four ends each twelve thumbbreadths long — then when the other two strings tear, if enough remains to tie it is valid; but if three strings tore even if enough remains to tie it is invalid. Therefore when three ends were cut, if one did not take care when making the tzitzis that the four ends on one side of the knot be recognizable, we worry perhaps each end is from one string and only one complete string remains — hence [with] doubt it is invalid.All the more so if one marked the four ends on one side and three ends on one side tore — invalid, for then surely three strings tore; if three tore on two sides also invalid lest three strings [tore].} But if only two ends tore we validate with kedei aniva; the halacha follows the first view, but where possible it is good to heed Rabbenu Tam. {Rama: And we practice like Rabbenu Tam (Agudah siman 15).) אבל אם לא נחתכו אלא ב' ראשים מכשרינן בכדי עניבה והלכה כסברא ראשונה מיהו היכא דאפשר טוב לחוש לסברת רבינו תם: הגה ונוהגין כר"ת (אגודה סימן ט"ו):
