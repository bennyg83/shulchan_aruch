“Enough to tie a bow.” Meaning “and they shall tie the breastplate”—Targum “veya’anvun.”

“All the strings.” The Gemara asks: enough to tie all of them together, or perhaps each alone? Rashi explained enough to tie the strings to each other—a large measure—end quote, hence they ruled stringently. Mordechai explained each alone: each snapped string must be able to tie one snapped string to each of the others individually—a longer measure than tying all snapped strings together—as Mordechai explains; even though Rabbeinu Yerucham did not explain thus, it appears to me his words are true, therefore one should be stringent that each string needs a bow-length on its own.

“That it snapped entirely.” Meaning on both ends no kezayis remained even by combining—then certainly invalid; if kezayis remained on both by combining, there is doubt whether it is invalid.

“Two ends.” And no kezayis remained; if kezayis remained on each end even if all snapped it is valid, as stated at the start of this siman—not like Eliyah Rabbah gloss 2.

“If he did not pay attention.” This is difficult—all the more if he did pay attention, as the gloss concludes. Some say he phrased “if he did not pay attention” because of the ending that follows; but if only two ends were cut, we validate with a bow-length specifically when he did not pay attention; if he paid attention, if two ends were cut from one side it is valid even without kezayis, for the other end remains as I wrote; but if two ends from two sides snapped and no kezayis remained on either, they are invalid lest they be one string. There is also a remedy: make a mark when tying the tzitzis so the two ends from one string are recognizable by knots at each string’s end—and perhaps therefore Rabbeinu Yerucham said “if he did not pay attention.”
