(In the Taz, comment 2)—it seems the mishnah deals with when there is no time remaining, etc.—meaning, one cannot say it deals with when there is time remaining, and nevertheless it is a mitzvah to stop; for specifically in seif 4, which deals with Torah matters, one could say it is a mitzvah to stop even when there is time remaining—unlike in the conclusion, which deals with the second day of Yom Tov, which is rabbinic; if so, there is no reason that it should be a mitzvah to stop, since there is time remaining and it is only rabbinic.
