Seif 4: If he read, etc. As stated, one who reads from the Torah may not read fewer than, etc., which implies that this is indispensable. Furthermore, otherwise there would have been no need during the maamados and on Rosh Chodesh to repeat or divide verses, since it is impossible to read ten complete verses there, as in Parashas Amalek. Rather, one must say that there the requirement is not indispensable after the fact, unlike here. This is what is meant by, “And if they did not,” etc. There is also proof from the Shabbos parashah that is not read, as stated below in siman 283. This entire seif is the wording of Shibolei HaLeket. It requires study that he writes, “But if they read,” etc., which implies even if each reader read three verses, such as by reading backward. Otherwise he should have said, “The one who read only two verses must return.” Moreover, he already wrote, “If one person read two verses,” etc. This is difficult from the case of the maamados and Rosh Chodesh, as he writes in seif 6, “or even two,” etc. One cannot answer that those cases are different because it is impossible, for then there would likewise be no proof from Parashas Amalek. In Maseches Soferim it is stated explicitly that only if they read ten verses does it suffice, but if they read fewer they must return. Hagahos Maimoniyos writes likewise, as stated in seif 3, and so too Tosafos in Megillah 23a, beginning “one.” This is the principal ruling: whenever they did not read ten verses, they must return.
And if they did not read, etc. This contradicts what was written in seif 3, as explained above. See Magen Avraham, though his explanation is forced.
