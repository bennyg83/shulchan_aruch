He should not set them into the building. Tur writes that it is forbidden to set them into the building. Regarding a house, however, Tur writes in siman 543, and the Mechaber copies in seif 3, only that it is proper to be stringent. Tosefes Shabbos answers that here, where he wishes to set the stones into the building, it is treated as an initial act. Magen Avraham, seif katan 10, implies that even this is considered after the fact because loss would result. In my humble opinion, the Mechaber deliberately departed from Tur's wording and did not write “forbidden.” His intent is that it is merely proper to be stringent, unlike Tur's position. This is also evident from Biur HaGra.
