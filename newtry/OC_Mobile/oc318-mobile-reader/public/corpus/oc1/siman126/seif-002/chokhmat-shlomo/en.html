Seif 2. If a chazzan errs and does not know where to resume, etc., the replacement begins from the beginning of the blessing in which he erred, etc. Note: This appears to apply only if the replacement did not hear the beginning of that blessing. If he heard it, he fulfilled that portion through the first chazzan and may resume from the point where the first stopped. This is analogous to Megillah reading in siman 693, where the later authorities disagree with Magen Avraham. See Shaarei Teshuvah in Hilchos Megillah, which rules that the replacement need only resume from where the first stopped, since he fulfilled the earlier portion through the first reader, as with shofar. The same should apply to the Amidah. Nevertheless, if it is a short blessing and there is no burden on the congregation, he should return to the beginning of the blessing. If this occurs on Rosh Hashanah or Yom Kippur, where repeating would greatly burden the congregation, he should begin only from the point where the first stopped, following the distinction in Shaarei Teshuvah in Hilchos Megillah. This appears correct as practical halachah.
