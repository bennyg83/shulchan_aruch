Seif 7, "threads," etc.; "not like," etc. As stated in Bava Basra 137a-b: rather here, if he can go out, etc. See Even HaEzer siman 28, seif 19. But otherwise he does not fulfill with borrowed ones from this verse, "for them," as stated there 27b, and as with lulav, as stated there: the baraisa teaches, Rabbi Eliezer says, etc.; and the Rabbis, this "for you," etc.; but borrowed, etc., is only because it is written "every citizen." So too we expound "your garment" to exclude a borrowed one, as written in Chullin 136.
