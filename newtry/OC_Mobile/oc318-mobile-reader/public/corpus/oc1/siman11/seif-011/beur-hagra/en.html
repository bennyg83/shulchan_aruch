"Some say," etc. From what is said: according to whom does that which Rabbi says follow, that tzitzis requires, etc.? This means along the length of the tallis, as Rashi wrote there; and below in seif 15, "some say that one must," etc. Also, since it says "on the gedil," but outside the gedil it is valid anywhere, and he explains gedil like Rashi's second language, as written in seif 11. He said it has no measure, meaning below; but above, certainly there is no distinction. Beis Yosef.

"And some say that the law," etc. From what is said: if he placed it on the edge or on the gedil, indicating that they are equivalent. Just as with the gedil there is no distinction, for the reason there is that it is not part of the garment, so too with the edge. See seif 11.

Seif 11, "if the gedil is," etc. This comes to answer the above difficulty, for we rule that even if it is wider than a thumb-breadth knot.

"Oriel." Rashi's second explanation.

"And if he placed," etc. Like Rabbi Eliezer ben Yaakov, for Rav holds like him. This is what he wrote: "on the corners," etc., from Rav's statement, and so too Rabbi Yochanan.

"But," etc., "good." End of Bava Kamma: Rav Yosef said, all goes up, etc.; and Yitzchak, etc.
