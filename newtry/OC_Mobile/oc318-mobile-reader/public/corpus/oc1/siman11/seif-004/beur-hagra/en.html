Seif 4, "the length," etc. According to the Rambam's explanation, for it must refer to the tzitzis; and like Rashi's first explanation in Bekhoros 39b.
"The eight." So it appears in the Gemara there, which says "tripled"; all the more according to Rabbenu Tam, who says it refers to the twisted section.
"Thumb-breadths." There, and Bekhoros there.
"And some say," etc. Like Tosafos' explanation there and there, that it refers to the twisted section. This is why it says "meshuleshes," an expression of gedil, and it is one third of the tzitzis, as stated on 39a. So too in the Sifrei regarding the gedil, cited by Tosafos there; see there. According to Rashi, six thumb-breadths; see Tosafos there and Bekhoros 39b, gloss beginning "kamah," etc.
"And if he made it," etc.; "and not," etc. Since it was not made in invalidity, as stated on 39b: they challenged, etc.; say: since, etc.
"One," etc. There: one wrapping thread, etc.
"And the measure," etc. As Rashi wrote in Bekhoros there, gloss beginning "meshuleshes teluyah," etc., and all the more according to Rabbenu Tam.
