(12) [Seif 3] If they came apart from their twisting, etc. — that enough remains in the twist for a coil. If enough for a coil did not remain, it is invalid even b'dieved — Ohr Torah sign 3; and so Kitzur Shulchan Aruch siman 9 sign 13: if any thread separated from its twist, all the separated part is considered as if cut off and is not [counted].

(12) That enough for a coil suffices only if something remained; but l'chatchila they must be twisted enough to darken, as will be explained below. If he did not do so, and from the outset did not twist except enough for a coil — one should invalidate it when another tallit is available; when no other tallit is available he should put this on without a blessing. The same if not lishmah in spinning or twisting — meaning if he did lishmah only enough for a coil and the rest not lishmah or stam — one should invalidate when another is available; Ohr Torah there.
