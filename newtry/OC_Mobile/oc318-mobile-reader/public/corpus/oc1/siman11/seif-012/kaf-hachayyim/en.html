12) [Seif 3] If their twist came apart, etc. This is valid only if a length sufficient to tie a bow remains twisted. If that amount does not remain, it is invalid even after the fact. See Olat Tamid, entry 3. Kitzur Shulchan Aruch, siman 9, entry 13, likewise writes that if any thread separates from its twist, the entire separated portion is regarded as though it had been cut and does not exist.
12) The rule that a length sufficient to tie a bow suffices applies specifically when that amount remained after the thread unraveled. Initially, however, the threads must be twisted for the full required measure that will be explained nearby. If they were initially twisted only for a length sufficient to tie a bow, one should treat them as invalid when another tallis is available; if none is available, he should put on this one without a blessing. The same applies when the spinning or twisting was not for the sake of the mitzvah: if only a length sufficient to tie a bow was made for its sake and the remainder was made not for its sake or without stated intent, it should be treated as invalid when another is available. Olat Tamid there.
