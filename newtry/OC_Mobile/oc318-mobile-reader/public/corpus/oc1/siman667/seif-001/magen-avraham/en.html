Also on the eighth. For if a meal happens during bein hashmashos, he must eat in it, and since it was set aside during bein hashmashos, etc.; Gemara. The same applies outside Eretz Yisrael on the ninth day: it is forbidden for this reason. This applies specifically to types of food, but he may take down cloths and sheets in order to adorn his house; Mabit, part 3, siman 163. This requires investigation in siman 638.
The custom is not to make use. Because since on Yom Tov it is forbidden, if he makes use of it on Shabbos it is called preparation. This requires investigation, for in siman 665 regarding an esrog he wrote without qualification that preparation does not apply; see there. Perhaps he came only to inform us that this is the custom, but not the law, for Tosafos too wondered about the custom.
It is forbidden to set up. This is the language of Maharil: If one carries from the sukkah a tabletop that they set on its legs and remove whenever they want, it is forbidden to set it up again in the house on its legs, for that is preparing from one Yom Tov day to the other; rather, he should place it on its side until night, and then set it up. End quote. It implies that it is permitted to set the tables in the house, and so it is implied in siman 666. In Hagahos Maimoniyos he wrote that it is forbidden to set up the tables and benches, arranging them for the needs of the night; so wrote Hagahos Minhagim. This implies that specifically arranging them is forbidden, but setting them up is permitted because of the honor of Yom Tov. But other preparations are forbidden. So too it is written in the Minhagim in the laws of Pesach, that it is forbidden to bring wine from one Yom Tov day to the other. Maharil also forbids searching out the Sefer Torah from Shabbos to Yom Tov because of preparation; see siman 416, se'if 2.
