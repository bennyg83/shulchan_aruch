Preparation. See Baer Heitev. See Eliyah Rabbah, who explains that 'to set up' means to set up their tabletop on legs. See Magen Avraham, siman 514, that it is forbidden to set up wax candles for the needs of the night. What he wrote in the name of Maharil regarding searching out the Sefer Torah, meaning to set the Sefer Torah at the section they will read on Yom Tov, is forbidden on Shabbos that is erev Yom Tov. From Shabbos to Yom Tov, so it is in Maharil. In Eliyah Rabbah he stated the reverse, from Yom Tov to Shabbos, and the Machazik Berachah wrote that one should be careful in both cases; see there.
