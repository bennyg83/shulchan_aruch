Se’if 3: Some say that even, etc. This is also implied by the Yerushalmi at the end of chapter 4: If he removed it before daytime ended, he may return it before daytime ended; if he removed it after nightfall, he may return it after nightfall. If he removed it before daytime ended and the day then became sanctified, R. Ba said in the name of Rav Yehudah: If the cavity was damaged, it is forbidden. Reish Lakish said: From R. Yehudah you can resolve the question. Just as he forbids it when the cavity was damaged, because this is considered insulating initially, so too, if it was removed before daytime ended, it is forbidden, because returning it is considered an initial act.
