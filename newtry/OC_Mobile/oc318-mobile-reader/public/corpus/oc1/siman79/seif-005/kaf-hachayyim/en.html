5) There: Four amos from the place where the odor ceases. Ateres Zekenim, paragraph 1, writes that some say one need move only to the place where the odor ceases. This is Rambam's view, which Maran did not accept, as explained in Beis Yosef. The later authorities likewise rule like Maran. God forbid that one should initially be lenient against them and rule like Rambam. Rambam's view may be followed only after the fact, if one already prayed, in which case he need not repeat the prayer, as stated in the preceding paragraph.
