If he placed hides in them. From this language it implies that even if the hides were afterward removed from them, and it dried and the bad odor was removed, the name of excrement is still upon them. From the language of Talmidei Rabbeinu Yonah on this matter, it does not appear so at first glance; see there, and see what we wrote nearby regarding this matter.
And if they have a bad odor, etc. This does not refer to the excrement of a dog or pig, but to other domesticated animals, wild animals, and birds. For regarding a dog and pig, Chazal knew that their odor is not bad as long as hides were not placed in them. So it is proven in the Gemara there, 25a: Rav said, the halacha is not, etc.; see there.
Their law is like human excrement. See Mishnah Berurah, where I wrote that even if the odor ceased, it is still forbidden. I wrote this because the Mechaber holds that its law is exactly like human excrement, and there it is forbidden in all cases, as in siman 82; see there. If so, according to this, certainly the excrement of a cat and all these things mentioned from seif 5 and onward are forbidden even if the odor later ceased. So too wrote the sefer Halacha Berurah. Nevertheless, this matter is not so clear to me, for perhaps in this respect it is lighter than actual excrement. So too it appears at first glance from the language of the Mechaber, who wrote soft donkey excrement, implying specifically while it is still soft, but if it afterward dried, it is permitted, although originally it was soft. One could reject this and say that the Mechaber intended only to exclude when it was dry from the outset, in which case the name of excrement never took effect upon it. Afterward I found in Pnei Moshe on the Yerushalmi that he wrote, while it is still soft, and it requires study in practice.
