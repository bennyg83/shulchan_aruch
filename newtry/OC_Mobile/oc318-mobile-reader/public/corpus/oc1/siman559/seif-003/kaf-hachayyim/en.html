3) Ibid. Tzidkascha is not recited, etc., and all the more so Tzidduk HaDin is not recited if a death occurred on Tisha B’Av. So too wrote the Rama at the end of this siman in the gloss. Taz, s.k. 1. Maharshal wrote in responsum 32 that Tzidduk HaDin is recited on Tisha B’Av even though Tachanun is not recited, see there. The Taz cited his words there. So too, the Rokeach, siman 317, wrote that there are places where Tzidduk HaDin is recited on Tisha B’Av, see there. However, Mateh Moshe, siman 734, wrote regarding the aforementioned words of the Maharshal that the custom not to recite it has already become widespread, see there. Eliyah Rabbah, entry 14, cited his words. So too wrote Eliyah Rabbah, siman 554, entry 18, that the custom is not to recite it, and so too wrote Chayei Adam there and Derech HaChaim, entry 9.
