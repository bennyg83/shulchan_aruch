If one erred and did not pray the afternoon prayer on the eve of Shabbat, one prays the evening prayer twice: the first for the evening prayer, and the second as teshuvah.The same applies if one did not pray the afternoon prayer on the eve of Rosh Chodesh — one prays the Rosh Chodesh [Amidah] twice. If one did not mention Yaaleh VeYavo in the first but mentioned it in the second, one must go back and pray again; but if one did not mention it in both, or mentioned it in the first and not in the second, one need not go back [Kol Bo, except for what he wrote that one prays the Rosh Chodesh [Amidah] twice].]:
