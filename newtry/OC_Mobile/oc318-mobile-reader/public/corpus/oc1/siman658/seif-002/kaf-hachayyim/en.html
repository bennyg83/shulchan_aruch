2) [Seif 2] On Shabbos it is not taken, etc. This is a decree lest one take it in his hand and go to an expert to learn, and thereby carry it four amos in the public domain. Sukkah 42b. Beit Yosef. Levush. Taz, s.k. 2.
3) Ibid., gloss: It is forbidden to move the lulav on Shabbos, etc. For use of its body or its place, it is permitted, as with a shofar at the end of siman 588. Taz, s.k. 3. Eliyah Rabbah, os 1. However, Maamar Mordechai, os 1, wrote that from the language of the poskim, who wrote that it is like a stone, it is implied that even for use of its body or its place it is forbidden, according to the law of all muktzeh machmas gufo. He expressed astonishment at the words of the aforementioned Taz, who brought proof from a shofar, for a shofar is different, since it is a utensil whose primary use is forbidden; therefore it is permitted to move it for use of its body or its place, according to the law of a utensil whose primary use is forbidden. A lulav, however, is forbidden according to all opinions; see there. So too wrote Mishbetzos Zahav, os 3; Nehar Shalom, os 1; Erekh HaShulchan, os 2; Bigdei Yesha; Beit Meir; Chemed Moshe, os 2; Machatzis HaShekel, s.k. 2; Chayei Adam, klal 66, os 13; Mishna Berurah, os 4. So too I wrote above, siman 308, os 51; see there.
4) Ibid., gloss: It is forbidden to move the lulav on Shabbos, etc. The same applies to the aravos and hadassim of the lulav, for the aravah is like a stone, as is the lulav, and likewise the hadas, since it is forbidden to smell it, as written above in siman 653. So too wrote Mishna Berurah, os 3.
5) Ibid., gloss: But the esrog may be moved, since it is fit to be smelled. Although it was written above in siman 653 that one should refrain from smelling it, nevertheless, if another item upon which one may recite the blessing over fragrance is before him, he may bless over that item and afterward smell this one as well; therefore it is not muktzeh. Taz, s.k. 4. Eliyah Rabbah, os 1. Magen Avraham, s.k. 1, wrote that since it is fit to be smelled on Shabbos it was not set aside; alternatively, he can recite the blessing over another fruit. End quote. This implies that according to the first reason he may recite the blessing over fragrance on the esrog itself even on Shabbos, as written above in siman 653. However, according to the Taz, even on Shabbos he cannot recite the blessing over fragrance on the esrog itself, and may only exempt it through another fruit. This is also the view of the later authorities, as written above in siman 653, os 3 and os 4; see there.
6) Ibid., gloss: It is forbidden to place it on a garment even on Yom Tov, because this creates fragrance. This is considered like completing a utensil. However, it is permitted to place it on the garment or padding on which it had rested before Yom Tov, because it has already absorbed the fragrance, as explained above in siman 511, os 47; see there. It is a fine custom to place the esrog in a small box and not in a cloth, because it creates fragrance if he changes the cloth. Moed LeKol Chai, siman 23, os 46.
7) Ibid., gloss: Because this creates fragrance. The widespread custom in Constantinople and these places is to wrap the esrog in a clean cloth. It appears to me that a reason may be given for the custom, for Maharil prohibited only placing the esrog directly next to the garment. The custom, however, is to wrap the esrog in tow and afterward place it inside a cloth, and there is no concern; there is no prohibition with the tow, because it has already absorbed the fragrance. Knesset HaGedolah, Hagahos HaTur, os 2. However, Eliyah Rabbah, os 2, wrote concerning the aforementioned words of Knesset HaGedolah that this does not seem reasonable, for if the fragrance passes through the tow into the cloth, he is still creating fragrance. End quote. It appears that this applies specifically when there is only a small amount of tow, so that the fragrance may reach the garment; but if there is a large amount, it is not reasonable that the fragrance will reach the garment. It further appears that this applies specifically when he places it today in the garment together with the tow in which it had rested before Yom Tov. But if before Yom Tov the esrog had already rested with the tow inside the garment, it is obvious that it is permitted to remove it and return it into the tow and garment on Yom Tov, because the garment had already absorbed the fragrance before Yom Tov, if it absorbs fragrance.
8) Ibid., gloss: Because this creates fragrance. See above, siman 511, os 47, where we cited a dispute regarding this when one does not intend to produce fragrance. In a pressing circumstance, when it is impossible for him to place it elsewhere, it is possible to rely upon those who permit it.
