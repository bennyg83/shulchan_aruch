S"k 7. All the more so here: placement is for tying. Per Leket Kemach, bedikah itself is a mitzvah — even if no chametz found, blessing for bi'ur not void since intent includes bi'ur if found (end siman 432) — so bless before bedikah. Here: though placement serves tying, placement alone is not mitzvah — if placed without tying, nothing; blessing void — bless before main act (tying). Taz (432) may hold blessing on tomorrow's bi'ur — still admits if nothing to burn, bedikah itself is mitzvah (bal yera'eh / lest eat). Taz's answer that bi'ur should be before — difficulty: must burn before issur time (434:5) — same for blessing; Taz 432:2 cites Rosh — bless at start. Here: placement not fulfillment itself unlike bedikah — as I understand.
