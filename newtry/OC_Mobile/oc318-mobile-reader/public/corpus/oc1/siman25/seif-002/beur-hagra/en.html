Seif 2, one who, etc., and should go, etc. Zohar, volume 3, 265a.
And there he should wrap himself, etc. Meaning, he need not wrap himself in a large tallis before tefillin, as above in seif 1, nor before going to the beis knesses, for all this is fulfilled with a small tallis. All the more so if he wishes to wrap himself in a large tallis beforehand, as written in the gloss, “and the common practice,” etc. See Taz seif katan 2.
