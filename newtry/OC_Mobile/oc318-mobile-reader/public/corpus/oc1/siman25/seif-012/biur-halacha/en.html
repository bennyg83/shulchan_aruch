"Knot broke" — if strap broke after donning complete, fixed and redonned: if minimum size remains (siman 27:8) — perhaps not like "slipped" but like intentional shift to return — no repeat; if totally invalid — repeat. Perhaps while still on head/arm counts as removal to return — see Beit Yosef.

"Another knot" — no difference same strap or new strap — blessing is on the tefillin themselves.

"Need not repeat blessing" — Mishnah Berurah: knot broke after head tightened — repeat (Magen Avraham: Shelah on slip — same as removal to return; many require blessing including Bach, Gra; Rama on removal to return — Shelah disputed; our case: slip during prayer uncommon — Pri Megadim, Aruch HaShulchan — blessers don't lose).

"Tightens and blesses" — blessing need not precede tightening (above se'if 8). If knot undid itself — Rama on shifting: no repeat; if untied manually and retied — no repeat. If opened tefillin to check parshiyot, resewn — perhaps repeat when redonning (mitzvah was suspended — unlike knot); compare tzitzit: invalid corner fixed while wearing — repeat (like knot after completion); if kosher but removing to attach nicer tzitzit — like removal to return (siman 8:14) — no repeat unless mitzvah lapsed from garment — doubtful.
