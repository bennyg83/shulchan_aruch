On Yom Tov. And the poskim wrote that nevertheless it is permitted to handle them, for they are not muktzeh, since they are fit for kindling. And Magen Avraham concluded: according to what he wrote in siman 495 that nolad is forbidden, if so the fats too are forbidden to handle when [the animal] was slaughtered on Yom Tov, for it is nolad, since from yesterday it was not designated for kindling. Rather, to store them away is permitted, for we permit their end for the sake of their beginning; but when it was slaughtered on erev Yom Tov, it is permitted to handle fats, for they are fit for kindling. And the same law applies to a piece of wax, for one can place a wick upon it, so it is fit for kindling; and it appears that if he set them aside for commerce, they are forbidden in handling. And a hide that was flayed on erev Yom Tov: if it is moist, it is forbidden to handle it; and if it is dry, it is permitted to handle it, as is written in siman 308, se'if 25. But when it was slaughtered on Yom Tov, it is nolad; and if it is moist, it is permitted to handle it so that it not spoil; but if it is dry, it is forbidden to handle it, for it is nolad; see Magen Avraham.
