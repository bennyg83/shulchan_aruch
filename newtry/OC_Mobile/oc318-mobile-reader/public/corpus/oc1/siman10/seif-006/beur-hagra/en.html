Seif 6, "there is no," etc. Per Rashi, the halacha follows him, as Rabbah in Rosh Hashana said, etc., and he explains what is written: "it is not a corner," etc.—even while it is still folded from when it was spread out though he did not fold it again; and likewise from when it says "do you think," etc.—it was not necessary to fold.

"But one must," etc. So Beit Yosef explains; but Darkei Moshe disagrees with him, for the language of exemption does not imply this:

"And even." So Rambam explains, as written: "it ends at the edges":

"And some say," etc. Like the first Tanna:

"And it is good," etc. This follows the view that writes that per Rambam one does not place tzitzis at all; see Magen Avraham:

"If he placed." This is the Rambam's language, explaining what is said there: "now, regarding bal tosif," etc. It challenges Rav Zeira's words in astonishment: surely both are invalid because of bal tosif, and all the more it is an act that invalidates. Rav Pappa answers: from where do you know, etc.; therefore the latter ones are valid.

"And there is," etc. Like Rashi's explanation there, and like Rava, unlike Rav Pappa, whose statement is only a difficulty.

"And before he cut," etc. From what is written: "do we say taaseh," etc.; thus before then it is invalid. So too in the words of Rava and Rav Zeira.

"The first ones." He wrote so according to what Beit Yosef concludes from Rosh's words, that it is specifically if he cut the first ones. This is not compelling—for the main novelty is that it is not subject to "from what is already made," and the Gemara's question and Rava's and Rav Zeira's words refer to this; but if he cut the latter ones, there is no need to say so.
