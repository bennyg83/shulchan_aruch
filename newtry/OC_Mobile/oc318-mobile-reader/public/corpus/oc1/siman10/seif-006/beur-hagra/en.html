Seif 6, "there is no," etc. Like Rabbi Shimon, for the halachah follows him, from what is said there: Rabbah bar Rav Huna, etc. He explains that "is this not the corner," etc., means even while it remains folded, since he threw it over and did not fold it; and also because it says, "do you think," etc., when he should not have folded it.
"But one must," etc. So explained the Beis Yosef; but the Darkei Moshe disagreed, because the language "exempts" does not imply this.
"And even." So the Rambam explains what is stated there: he fastened it with pins.
"And some say," etc. Like the first tanna.
"And it is good," etc. This follows the opinion that according to the Rambam one does not place tzitzis at all; see Magen Avraham.
"If he placed." This is the Rambam's language, explaining what is said there: "now, regarding bal tosif," etc. It challenges Rav Zeira's words in astonishment: surely both are invalid because of bal tosif, and all the more it is an act that invalidates. Rav Pappa answers: from where do you know, etc.; therefore the latter ones are valid.
"And there is," etc. Like Rashi's explanation there, and like Rava, unlike Rav Pappa, whose statement is only a difficulty.
"And before he cut," etc. From what is written: "do we say taaseh," etc.; thus before then it is invalid. So too in the words of Rava and Rav Zeira.
"The first ones." He wrote so according to what the Beis Yosef concluded from the Rosh, that it is specifically if he cut the first ones. This is not compelling, for the main novelty is that it is not considered "from what is already made," and the Gemara's question and the words of Rava and Rav Zeira refer to this. But if he cut the latter ones, there is no need to say it. So too in the words of Remez and Rabbenu Yerucham, and so wrote the Magen Avraham.
