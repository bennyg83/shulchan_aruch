Abudraham; and see Eliyah Rabbah he need not start from beginning only from where first stopped — see there; Shulchan Aruch ch. 1 siman 42 agreed; wrote: if one says what matter starting from beginning — Chazal were very strict about tircha de tzibura etc. — only finisher should be at time of blessing first blessed as shofar siman 691 seif 3 — see there; likewise Degel Merubah megillah like shofar discharging — starts where stopped; and if only few verses read — no great tircha — start from beginning; also if majority agree start from beginning; Purim night Motzei Shabbat good to start from beginning lest souls be gloomy reading in halves; other days fast hard — lighten as Eliyah Rabbah and Shulchan Aruch start where stopped; see Shaarei Ephraim shaar 6 seif 60 and Pitchei Shearim there at start.
