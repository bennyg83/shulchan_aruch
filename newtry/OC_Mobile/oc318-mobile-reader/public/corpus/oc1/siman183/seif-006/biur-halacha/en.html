Other side: siman 65 shema if waited between blessings does not return—here because delay each other all considered one blessing; also siman 188 s.10 returns to start Rosh reason three birkat hamazon blessings one—so I wrote Biur Halacha. Now after searching books: delay each other not settled—siman 194 Magen Avraham Ramban not clear; Even HaEzer Rif too do not delay each other; three blessings one only Rosh and R' Yehudah many poskim disagree siman 188 Biur Halacha—no proof for birkat hamazon if waited between returns; even mid-blessing forced finish—perhaps only start of that blessing; many disagree three as one; Even HaEzer perhaps no delay—then only return to start that blessing like siman 65 shema; requires study.
