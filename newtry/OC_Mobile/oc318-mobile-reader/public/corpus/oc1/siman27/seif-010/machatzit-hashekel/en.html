(s"k 10) Since he writes, etc. Since he also writes with the right — i.e. per this view it depends only on writing; the writing hand is called right though he does all work with the other — he rules both hands, dons on left like everyone.

Bach disputes, etc. Gemara has two drashot: yadekha = left (R. Eliezer); yadekha = weak hand — main view follows the hand that does all work (first "some say" in Shulchan Aruch). Per "bind and write" — writing right, tying right — must don left to tie with right. Last "some say" in Shulchan Aruch: depends on writing hand; Bach holds last view nullifies right/left for everyone — requires both anomalies: all work with left and write with left; thereby dons on right, which is the weak hand.

Also fulfills "bind and write" — he writes with the left.

But with only one anomaly — dons left like everyone. Thus the last case in Shulchan Aruch — writes left, all work right.

Also the last "some say" agrees he dons left. Since only one anomaly on the right (does not write with it). They dispute only the first case — writes right, works left: first view — only weak hand, don on right; last view — also left since only one anomaly on right (it is weak). "Bind and write" can be fulfilled on the right per force.

However, etc. If he later accustomed himself to write left — may rely on Bach, for anyway Mordechai has views that this is not called lefty (Magen Avraham s"k 9). We do not rule so, since Rama in Shulchan Aruch implies like Mishbetzot Zahav citing Mordechai that even this is lefty; if he accustomed himself to write left, with Bach's view — don left like everyone.
