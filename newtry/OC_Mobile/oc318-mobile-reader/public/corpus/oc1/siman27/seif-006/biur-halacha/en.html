And lefty — his right hand — See Mishnah Berurah "even if became," etc.; Magen Avraham s"k 9 Mordechai — though disputants, end s"k 10 — halachah like Darkhei Moshe; Darkei Moshe ruled. "All the more if from heaven" — Dagul Merevavah — all agree becomes lefty; if right palm amputated — lefty (as inside). Peri Megadim doubts Dagul Merevavah — still rely on Dagul Merevavah; even habitual lefty — Darkhei Moshe rules lefty. If left amputated, only cubit — obligated on cubit; if right amputated, only cubit — obligated; after habituating left, right became left.

Places on his left — Mishnah Berurah, Chut HaShani; Sha'arei Teshuvah — Ittur in Beit Yosef siman 651 seems yotzei — words unclear: Ittur means after tefillin law — don left which is everyone's right; for lulav bedi'eved yotzei; tefillin if reversed to his right (everyone's left) — not yotzei — lefty his left is everyone's right. Chut HaShani explains Ittur as we wrote.

And some say — hand that writes, etc. Shulchan Aruch and poskim — any writing suffices, not full sta"m script; if only scrawl not sta"m — uncertain; Rambam Shabbat 11 yud — two marks (Magen Avraham) — uncertain. Such case — better Gra and majority (first view); Aruch HaChayyim expanded.

And thus practiced — Magen Avraham: this view — even controls both in writing — left like everyone if other work left; Bach disputes — only if writes right, other work left = controls both; writes left, work right — left of everyone; we follow Shulchan Aruch only (many acharonim); Aruch HaChayyim held Bach lehalachah; Gra fully first view — no following writing; writes right, work left — right; still recommend world practice aliba dikulai — Jewish custom is Torah: even first view — writing hand cannot do other actions; if that hand can do others, only easier on other — "controls both" for all, since other cannot write — each hand has its role — unlike Mishnah Berurah s"k 25 "controls." Learned from Sha'arei Teshuvah siman 651 lulav — writing no special status, single action; here first view tefillin — still "controls both" by this reasoning; so here even first view and Gra — writes right, work left because easier — don left like everyone.
