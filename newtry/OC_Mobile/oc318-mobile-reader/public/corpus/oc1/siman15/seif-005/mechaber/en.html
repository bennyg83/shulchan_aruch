If [the fabric] tore from the hole the <i>tzitzis</i> hangs in downward — if tying <i>tzitzis</i> preceded the tear so that <i>tzitzis</i> was there at the tear, it is valid. If it tore and something remained and one sewed and afterward tied <i>tzitzis</i>, if wool [garment] all agree it is valid; if of other kinds where one sews with that species’ thread, according to Rashi one does not sew; if one tore, sewed, and afterward tied <i>tzitzis</i>, there is a doubt.
