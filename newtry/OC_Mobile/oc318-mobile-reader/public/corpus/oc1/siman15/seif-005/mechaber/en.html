If [the fabric] tore from the hole the tzitzis hangs in downward — if tying tzitzis preceded the tear so that tzitzis was there at the tear, it is valid. If it tore and something remained and one sewed and afterward tied tzitzis, if wool [garment] all agree it is valid; if of other kinds where one sews with that species’ thread, according to Rashi one does not sew; if one tore, sewed, and afterward tied tzitzis, there is a doubt.
