(1) [Seif 1] One may not produce fire, etc., and the reason is because he generates on Yom Tov — Beitzah 33b. Rambam wrote beginning of chapter 4: because only kindling from existing fire was permitted on Yom Tov, but generating fire is forbidden since it is possible from erev Yom Tov — end quote; Maggid Mishneh wrote there that if he generated it is permitted to use. Bach, Beit Yosef, Bach — see there note 1 Magen Avraham note 1. However Taz disagrees and wrote that not only l'chatchila is it forbidden to cook in that fire, but even if he transgressed and cooked the food is forbidden whenever Israel generated the fire in prohibition, and its law is like cooking on Shabbat — see there. So too Peri Chadash on Maggid Mishneh's words that it is not required; but Levush wrote like Maggid Mishneh that if he transgressed and generated it is permitted to use. So too Perishah note 1, Taz; so too Rabbi Akiva Eiger note 3 to reject all Taz's words and agreed to him Birkei Yosef note 2 and Bigdei Yesha — see there. So too Maamar Mordechai and Nehar Shalom note 1 and Chayei Adam note 2 rejected Taz's words — see there. See Radbaz vol. 2 in words of Rambam end responsum 150 that Rashba wrote explicitly it is permitted and wrote Taz's reason is correct — see there; Nehar Shalom brought it there. So too Rabbi Zalman note 1 Chayei Adam kelal 95 note 12. Mekor Chaim siman 2 note 1, Mishna Berurah note 4.
