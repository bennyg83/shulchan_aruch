Seif 11 "bridal canopy" etc. "behold" etc. The language of Rambam, and so too Ran — so the Rosh's difficulty from what is in seif 5 is not a difficulty; and he omitted what is stated "and there is not in the slope a tefach" — there is no such version for him; and likewise Tosafos in the name of Rashbam challenged from what is stated in Sukkah 19b that we rule it is not considered like ohelim; and so too Beit Yosef — there is no such version for this regarding slope of a tefach; and so too in Maggid Mishneh's words; but the Rosh and Tur wrote it, and so Shulchan Aruch, and as Rashi explained; and it is possible that even Rambam had such a version, but he holds there is no halacha like him here, for he holds like the Sages of the mishnah in chapter 1 of Sukkah, and we do not rule thus; and see Tosafos s.v.
