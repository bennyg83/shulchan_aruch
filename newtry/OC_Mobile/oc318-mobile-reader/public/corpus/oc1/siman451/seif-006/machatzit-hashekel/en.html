(א) (s.k. 6) Kasher them, etc. Gemara implies: Ravina to R' Chisda — these Pesach knives how? I make new; if possible for you; not possible? Like new — handle clay (not burn at libun), iron in fire, then immerse boiling — conclusion both (handle and iron) in boiling kli rishon. Simple meaning R' Chisda answered like new — initial intent when said I make new — like new: handle clay, etc. — possible for anyone; for R' Chisda no difference possible/impossible — always like new; therefore halakha both in boiling applies possible and impossible — even possible suffices boiling.

(ב) Holds this is Gemara meaning, etc. For impossible — so R' Chisda intent: since said possible I make new — without possible do like new; but possible — actual new; though conclusion boiling — may apply only impossible; possible should make new as R' Chisda — also for R' Chisda difference possible/impossible — same per halakha conclusion — see Taz.

(ג) As YD 121: why knife from non-Jew needs libun — non-Jew uses on fire; chametz lenient — Israel not customary use knife on fire though sometimes — Mechaber goes other vessel majority use as seif 16; we stringent Rama gloss there — nevertheless rely permitted absorption chametz this — Kaf HaChayyim, Peri Chadash YD lenient even issur knife hagalah — nevertheless new preferable.
