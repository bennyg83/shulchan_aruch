(27) In the gloss there — forbidden to use it even cold, etc. — meaning in a fixed manner, lest one come to use it hot; and if so, even if they rinsed first it is forbidden; but in an occasional manner it is permitted to use it via rinsing — and not like Orchot Chayim; and a fixed manner — even orally after its prohibition time — it is forbidden to use it. Chayei Adam note 11. Eshel Avraham note 4. Mekor Chayyim note 8. R' Zalman note 2. However with old pottery vessels the custom is not to use them even cold and even in an occasional manner, as written below end seif 22; see there.
