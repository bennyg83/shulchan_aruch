(17) There — except that one pours boiling water into them. This is Tur's language; and Beit Yosef explained: even if one did not use pottery vessels boiling, only in kli sheini — heating does not help for them; and he wrote so too Rambam chapter 5 equates pottery vessels used with chametz in kli sheini to using them in kli rishon — until here. However Rabbeinu Moshe z"l in Darkei Moshe note 1 wrote it does not appear to him Beit Yosef's explanation — rather according to Tur kli sheini has a remedy because it does not absorb; but in the name of Hagahot Maimoniyot he wrote that even if one did not use a pottery vessel except in kli sheini — heating does not help for them; see there; and to this Rabbeinu Moshe z"l wrote in the gloss on Shulchan Aruch's words that it is Tur's language; and one says: even in kli sheini — meaning that although this language of Tur implies specifically if used via pouring from kli rishon it has no remedy — but if used in kli sheini it has a remedy; one says: even in kli sheini it has no remedy through heating. And so Chayei Adam note 8, Eshel Avraham note 3; and regarding the law see below note 37.
