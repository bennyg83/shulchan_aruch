A vessel that has a patch — it appears that wherever there is a patch and the adhesion is from fire such that chametz cannot enter there b'eyna, then hagalah before the adhesion helps; but if there is not strong adhesion, what does hagalah before adhesion help — for there is concern lest chametz enter there b'eyna at the time of adhesion; therefore it does not help unless one places coals there to burn the chametz. All this is regarding a patch that is attached with nails; but a patch that artisans make on a tin or silver vessel — there is no concern here, for through the heat what was absorbed in it is burned, as above; and it is simple. One should pound all spices before Pesach, and if he did not do so it is permitted on Pesach itself if he kashered it before Pesach. The practice is not to kasher a vessel in which yayin nesech was — as Levush writes — and it appears that if one cooked in it with water and earth until the smell entirely departed, there is no prohibition to kasher it afterward.
