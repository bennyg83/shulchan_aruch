If it is repulsive. It implies from Toras Chatas, rule 22, that even in a place where it is permitted for eating, it is forbidden for the Most High if it is repulsive. So Bachya wrote, and so it also appears from Rabbeinu Yerucham and the Rosh in the chapter Gid HaNasheh. However, in Toras HaBayis, bayis 4, sha'ar 1, he wrote as follows: if it is in a manner that it is forbidden for eating, it is forbidden for lighting. So the Taz ruled in Yoreh Deah, siman 114. See siman 272.
