Seif 6, if he extended, etc. According to the explanation of the Ramban, the Yerushalmi, and the Rosh there, seif 8.
And some say. According to the first explanation there. The Rashba proved the Ramban's explanation, for according to the first explanation, even the first tekiah does not count for him, as written in seif 8. The second view holds unlike what is written in seif 8, and like our text in the Tosefta, and as the Rashba wrote: if he blew a tekiah, sounded a teruah, blew a tekiah, sounded a teruah, and blew a tekiah, he has only one; that is to say, the first order, for the plain blast after it does not count both here and there. This is the same as the Mishnah's case of extending the second blast, etc., for we require the third blast of three. Nevertheless, all agreed to the ruling of the Ramban in seif 8, and if so here too the first view is primary; and so the Rosh and other poskim agreed.
And if he blew, etc. As written in siman 588, seif 4: if he was, etc.; and likewise from what is written on 28a regarding verses, etc. But as to whether it counts for here or for there, it does count. See Tosafos there, s.v. 'the measure.'
