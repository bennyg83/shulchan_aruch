There, but more than nine it is. This is not precise; rather, one must make the forces slightly less than nine tromitin. It seems more that the Taz did not write this as an explanation of the Mechaber, but wrote it as practical halacha, for he holds like Hagahos Ashri, as the Taz wrote afterward. Consequently, it is permitted to extend nine tromitin, for each groan is a bit more than a yevavah, which is three tromitin; if so, shevarim contain nine tromitin and three slight additions. This is easy to understand.
