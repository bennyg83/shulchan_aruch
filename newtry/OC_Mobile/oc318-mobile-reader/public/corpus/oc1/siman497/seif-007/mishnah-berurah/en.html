{19} It should say "brought from trapping," etc. — see above siman 506 Mishnah Berurah note 1, and there it is explained that whatever cannot be caught in one run but needs to catch its breath before one reaches it is as if it should say "brought from trapping and was trapped." And per what is explained there regarding a bird — even if it was in a cramped place where it could be caught in one stretch, nevertheless if the window or roof is open so it can escape there, it is forbidden to trap it.
