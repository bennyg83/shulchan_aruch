{19} Where one must say, 'Bring a net,' etc. See Mishnah Berurah above, siman 316, seif katan 1. It is explained there that whenever one cannot catch the animal in a single pursuit but must rest before reaching it, this is considered a case where one must say, 'Bring a net and let us trap it.' According to what is further explained there, regarding a bird, even if it is in a confined place where it can be reached in one movement, it is forbidden to trap it if a window or roof opening remains through which it can escape.
{20} It is permitted to trap them, etc. This applies if he designated them, so that muktzeh does not apply. Otherwise, it is forbidden to catch them, since they are also forbidden to move.
