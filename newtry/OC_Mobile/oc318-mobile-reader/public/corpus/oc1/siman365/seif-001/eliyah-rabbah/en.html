[1] [Levush] The same applies if he did not, etc. The Beit Yosef writes this in the name of Rashi. This requires study, because Tosafot, s.v. cholkin, says that if a strip four handbreadths wide did not remain, the breach is treated like the original opening of the alleyway and requires a board four amot long. So too it appears from Rabbi Yonatan and the Tur, and the Bach, Malbushei Yom Tov, and Magen Avraham rule accordingly.
