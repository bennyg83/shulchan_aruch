Half. See Taz. According to the first opinion it is impossible to determine an exact half, whereas according to the second opinion it is possible. If so, one can measure it, and if it is precisely half it should be kosher. Yet the phrase “we are stringent because of the doubt” implies that Taz's own view is to be stringent. See Eliyah Rabbah, seif katan 21. In seif 4 Mechaber rules leniently regarding an unresolved question because it is D'Rabbanan. We wrote there that this was because the Gemara's proposed proof indicated that an internally decayed esrog is kosher. See Kappos Temarim, which I cited above.
