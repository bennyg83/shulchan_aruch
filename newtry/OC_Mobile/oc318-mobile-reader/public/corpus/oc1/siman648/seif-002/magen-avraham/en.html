Perforated through. If the thick peel was pierced from this side to that side, it is called perforated through according to all opinions.
Like an issar. For example, where he inserted into it a broad peg. See Yoreh Deah, siman 34, seif 3, regarding the measure of an issar. It seems to me that if the hole is square or long, we see whether, if you would round it, it would be like an issar; if so, it is invalid. So too in Yoreh Deah, siman 34, regarding the windpipe, unlike what the Knesses HaGedolah wrote in the name of the Radbaz, who inferred from the Rambam's wording to validate it if it is square until an issar can enter into it; see there. This is not sufficient grounds to be lenient based on a slight inference, for one can say that the reason the Rambam wrote or more is to teach that even if it is larger, it is valid on the other days.
