[3] There, in Magen Avraham, se'if katan 3. "And so wrote Responsa Maharil." Note: this is the language of Maharil in that responsum: a proof that meat of a slaughtered animal is not permitted together with neveilah in every case, even if both are one type, even according to the view that the same type mixed with the same type forbids in the smallest amount. So it is also proven in chapter Keitzad Tzolin, where it asks, according to the view that the reason is mixture of flavors: what difference is there between a kid and a kid, or a kid and a lamb? Let it say that it is not necessary to mention a kid and a kid, because that is the same type with the same type, etc.; and according to R. Yehudah and Rebbi, who arranged the Mishnah, the same type with the same type forbids in the smallest amount, etc. Through this he repaired the words of Magen Avraham, se'if katan 4, and this is easy to understand.
