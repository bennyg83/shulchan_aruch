"For if it does not have sixty, he transgresses regarding it, and so ruled the Tur, etc." This means that the Tur wrote there that if it has flavor, one is biblically liable for it; see Magen Avraham, se'if katan 1. Therefore he wrote that with the same type mixed with the same type, where there is no taste, if so one does not transgress regarding it, as is also explained in the above siman, and it is permitted after Pesach if he kept it. But to mix it and keep it may be forbidden in such a case. For although anything over which one does not transgress biblically may be mixed and kept, that is specifically where it is made for souring and does not contain enough to eat a kezayis within the time of eating a peras. This is not so here, where it is less than sixty, and against it, if it were not the same type, it would impart flavor. Therefore, even though it is the same type, it is forbidden to mix intentionally and keep, as a decree lest he do so with a different type. He wrote that perhaps this is what R. Yerucham wrote, that if one nullifies it, etc., about which the Tur asked: either way, if it is something over which one transgresses biblically, nullification does not help at all; and if one does not transgress, even mixing it ab initio to keep should be permitted. About this Magen Avraham wrote that perhaps it refers to such a case, where there is enough to impart flavor, but it is the same type; in such a case it is forbidden ab initio, as appears to me. See what I wrote in siman 442 until "and if less than a kezayis became mixed, etc." That is not from the Bach, but Magen Avraham's own words. What he wrote, "and if it became mixed, etc., this is what he intended in the gloss," is from the Bach, who wrote that from Rema's language it sounds that it refers even if he knew before Pesach and transgressed and kept it, redemption helps. This means it refers to where there is not a kezayis of chametz there. This is unlike Hagahos Maimoniyos, who wrote that it must not have been known; that refers to where there is a kezayis of chametz there.
