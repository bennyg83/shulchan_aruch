6) If they erred and read the order of the four parshiyos in the first Adar, they must return and read them in the second Adar, as stated in Megillah 6b, for the halachah follows Rabban Shimon ben Gamliel, see there. So too ruled the Tur in siman 688, based on the emendation in Bedek HaBayis that appears there in the Beit Yosef. So too wrote Darkei Moshe and Bach there.
