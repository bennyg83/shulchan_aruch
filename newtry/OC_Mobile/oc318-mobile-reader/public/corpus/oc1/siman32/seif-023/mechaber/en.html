If he found that one letter is missing, there is no remedy, because if so, they would have been written out of order and would be invalid, since it is written 'and they shall be,' meaning they must remain in the state in which they were written. If one letter is extra, there is a remedy by scraping it away if it is at the end of a word or at its beginning. But if it is in the middle of a word, there is no remedy, because when he scrapes it away it will appear like two words.
