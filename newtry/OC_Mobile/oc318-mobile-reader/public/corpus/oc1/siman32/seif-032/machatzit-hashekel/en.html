(s.k. 32) Initially… when dipping the quill one must sanctify the ink… in letter 1… but Yoreh De'ah 276 se'if 4 in Rosh's name: another reason — when dipping do not immediately write the Name lest excess ink — rather intend to leave one letter unwritten before the Name; if not, seek a letter needing ink, end quote. Shakh: "seek" implies writing another mundane letter on some skin is forbidden since… see there.

Then he dips in the letters before the Name, etc. This implies that in letters of the Name that were already written one should not dip; and see Yoreh De'ah siman 276, likewise in the hagahah, and in the Shach there, that it is somewhat implied that it is permitted if he wants to write a mention of the Divine Name in them.
