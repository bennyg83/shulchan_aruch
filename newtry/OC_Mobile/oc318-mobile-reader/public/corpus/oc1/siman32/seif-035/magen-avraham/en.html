Beit Shmuel wrote: from the fact that he doubled the word "must" it implies that even b'dieved it is invalid — even in other divine names that are not erased, and even if a letter attached to the Name extended beyond the line after it, it is invalid if it went outside the line, as above — for halachah but not for practice. So too in the rulings of Mahari Weil siman 93, who wrote that "must" implies even b'dieved, etc., see there. Nevertheless there is difficulty, for we find many places where "must" means l'chatchila, as Bach wrote and siman 119 and the first chapter of Gittin. Also Shach in Yoreh De'ah siman 276 se'if 7 wrote that some poskim validate when one hung part of the Name — if so it seems all the more so when it went outside the line, for the prohibition of hanging is mentioned in the Gemara, whereas this prohibition is not mentioned explicitly in the Gemara but only from the words of Rabbeinu Tam — and whence to disqualify b'dieved? See siman 18 in the name of Rabbi Meir Galanti. In Mishnah Berurah siman 57 he wrote: if one wrote "Elokenu" without a yud, it is permitted to hang the yud afterward since it is not from the Name itself, end quote — if so, all the more so if a letter attached to the Name went outside the line it is valid, as Maharik root 131. The genius, wonder of our generation, our rabbi Rabbi Yitzchak Av Beit Din of the holy community of Pozna ruled to erase all the upper lines and extend them so they are level with the Name, since it is possible to fix them it is not called b'dieved, as Maran wrote siman 39 se'if 2 in the name of Rabbi Meir Lublin. But if there is a Name in the upper lines that may not be erased, it is valid b'dieved.
