The order of the blessings, etc. Tur records this in the name of Rav Hai without distinguishing between an individual and a congregation. Beit Yosef questions this, because Rosh and Rashba cite Rav Hai as distinguishing: For a congregation, only the order is not indispensable, but the blessings themselves are indispensable; for an individual, even complete omission is not indispensable. Tur apparently contains a scribal error and should read: 'Rather, only in this respect did the Gemara say they are not indispensable: If he reversed the order, reciting the first blessing last and the second first, it is not indispensable. The Yerushalmi's case concerns specifically an individual; for a congregation the blessings are indispensable.' For practical halachah, the Shulchan Aruch rejects Rav Hai's distinction between an individual and a congregation, following Rashba's conclusion.
