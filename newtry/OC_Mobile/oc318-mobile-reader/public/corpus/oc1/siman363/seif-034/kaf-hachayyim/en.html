34) There. One handbreadth wide. It appears that if this lechi is made from the wood of an asheirah, it is invalid. Since this lechi must measure one handbreadth, it is comparable to a korah made from the wood of an asheirah, discussed below in se'if 16, which is invalid. Since it requires a minimum measure of one handbreadth, we apply the principle that an object designated for burning is viewed as pulverized and therefore lacks the required measure. The same consequently applies to this lechi. Tosefes Shabbos, subsection 8.
