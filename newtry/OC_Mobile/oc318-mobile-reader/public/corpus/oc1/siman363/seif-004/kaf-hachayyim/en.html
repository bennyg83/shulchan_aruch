31) [Se'if 4] If there is a small portion of wall, etc. Although it was not made for the purpose of serving as a lechi, we rule that a lechi that stands on its own is valid, as stated below in se'if 11. See there.
32) There. Provided that it is one handbreadth wide. Although the Shulchan Aruch writes that a lechi of any width suffices, that applies when the lechi stands independently. If it is attached to the wall, it is recognizable only if it is one handbreadth wide. Olas Shabbos, subsection 4. This follows the distinction made by the Shulchan Aruch in se'if 2 between a strip made deliberately and one left as a remnant of the wall. However, we already wrote there in subsection 14 that some authorities hold that any width suffices even when a remnant remains. According to them, the same applies here. Tosefes Shabbos, subsection 4, has already challenged the Levush's distinction between the two cases. See there. Nevertheless, we wrote there that initially one should forbid carrying when the remnant is less than a handbreadth, in accordance with the Shulchan Aruch and the authorities who agree with him. The same therefore applies here.
33) There. One handbreadth wide. The same applies to a tzuras hapesach: when a remnant remains, it must be one handbreadth wide. Tosefes Shabbos, end of subsection 10. Shaarei Teshuvah below, on se'if 26, writes concerning these words of Tosefes Shabbos that this is not conclusive. See there.
34) There. One handbreadth wide. It appears that if this lechi is made from the wood of an asheirah, it is invalid. Since this lechi must measure one handbreadth, it is comparable to a korah made from the wood of an asheirah, discussed below in se'if 16, which is invalid. Since it requires a minimum measure of one handbreadth, we apply the principle that an object designated for burning is viewed as pulverized and therefore lacks the required measure. The same consequently applies to this lechi. Tosefes Shabbos, subsection 8.
