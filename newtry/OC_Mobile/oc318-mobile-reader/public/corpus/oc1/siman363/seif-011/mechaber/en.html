**11.** Even if it was not placed there as a lechi but happened to be there on its own, it is valid — provided one relied on it before Shabbat. But if one did not rely on it before Shabbat — for instance, there was another lechi and it fell on Shabbat and now one wishes to rely on this one — no.((But if there was no other lechi there before Shabbat, it is as if one had relied on it.).
