(35) [seif 5] A lechi that if wind blows in it, etc. And this is because we say any partition that cannot stand in a normal wind is not a partition — and the same for lechi. Beit Yosef. See there ot 5; and even if the wind does not knock it down but only shakes it it is invalid as Maharshal siman 362 wrote, Magen Avraham s.k. 4; and this means if wind blows it nullifies the partition — if not one could say it is valid.
