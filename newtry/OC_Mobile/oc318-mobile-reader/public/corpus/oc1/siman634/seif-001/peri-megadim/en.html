Seven by seven, etc. See Turei Zahav, who agreed with what the Magen Avraham wrote in letter 1, and as the Mechaber wrote in se'if 2, that a round sukkah needs enough space to square seven by seven handbreadths. In Tosafos there, the word "only" should be inserted: "seven by seven handbreadths"; and so wrote the Magen Avraham. See the Rambam, chapter 4, regarding adding several mil to its length. So too the Mechaber wrote. The Bach wrote that there is no concern that it is not a temporary dwelling because one would need to strengthen the walls, for according to Rava this is what is taught; see there. If one placed s'chach over a karpef that was not enclosed for dwelling, it requires analysis whether one may carry on the Shabbos during Sukkos. See siman 630 in the Magen Avraham, letter 9, and examine the Magen Avraham about this. There is a scribal error in the printing, and it should read: "for if it is a handbreadth wide and several handbreadths long, it is obvious that it is not a dwelling, etc." See what I will write, with Hashem's help, in the following letter.
