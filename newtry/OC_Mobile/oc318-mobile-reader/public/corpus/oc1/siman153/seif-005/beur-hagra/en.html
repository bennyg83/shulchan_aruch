Seif 65 — if, etc.; but there: if they collected and had surplus, it is permitted; but if they did not have surplus, it is forbidden.

And if when they collected, etc. — Hagahot there (s.v. afilu lo) in the name of Or Zaru'a; and it requires study why it does not answer there like this case.

But if not so — there, s.v. Ilima, etc.

And if they bought, etc. There 26b: but in new ones, etc.; and Beit Yosef asked what he wrote from collected money that it is forbidden to change them, as explained; and likewise when they bought from the money for stones and wood; and explain that which he wrote "in new ones," etc. — meaning before it came into the treasurer's hand, as written in Arakhin 6 and Tosafot there; and it is written, and it appears more that which he wrote "in new ones," etc. — not that it should return, but to lend them; and Tosafot Bava Kamma 36b s.v. yad, etc., and Rabbenu Tam explained, etc.; and see Yoreh De'ah siman 258 seif 66 and siman 259 seif 61; and see Magen Avraham note 5 and Taz note 2.
