A hadas of the mitzvah. Since its main purpose is only to smell it, from this it was set aside for all seven days, like sukkah wood. But the esrog's main purpose is eating, and it was set aside only from that, not from smelling. Rather, they disagree about the berachah, for some say that since it was not made for fragrance, the berachah 'Who gives a good fragrance in fruits' does not apply to it. Therefore one should not smell the esrog all seven days. See what I wrote in siman 216. The Semak wrote: those who smell it when reciting the berachah on taking it have a foolish custom.
