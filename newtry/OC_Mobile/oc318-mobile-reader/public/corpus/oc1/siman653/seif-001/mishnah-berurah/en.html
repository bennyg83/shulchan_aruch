(1) It is prohibited to smell, etc. - Since its main purpose is only to smell it, from this it was set aside for all seven days, like sukkah wood. But the esrog's main purpose is eating, and only from this was it set aside, not from smelling. Rather, there is a dispute regarding the berachah of 'Who gives a good fragrance in fruits,' for some say that since it is not made for fragrance, because it is for the mitzvah, one should not recite a berachah over it. See Beis Yosef in the name of the Rashba regarding whether a condition helps with hadas, and see siman 664:9.
(2) It - Even on Shabbos, although we do not take it on Shabbos, nevertheless it was set aside for all seven days. But an esrog is permitted to smell on Shabbos, for in any event now it is not being used for the mitzvah [Magen Avraham and other Acharonim].
(3) From smelling it - At the time of taking it for the mitzvah. But before or afterward, if he smells it, according to everyone he may recite a berachah. Some say that one should refrain all seven days; see above in siman 216, where we explained all the details of the law.
