Seif 3, if he was, etc. For we hold like Rabbi Meir, and so Tosafot there, s.v. ‘al,’ ruled, and the Yerushalmi, etc., says, ‘and so is the halacha,’ etc. So too it is found in Tanchuma, etc., and so the Rif wrote, as we say, ‘and Rabbi Yehuda follows his reasoning,’ etc. The same applies: Rav Yehuda holds that the mitzvah requires intent like Rabbi Elazar. But the Raavad ruled that this applies specifically until ‘upon your heart,’ because the reason is so that he not make it casual, as written in seif 6. So too was written above, siman 58, seif 3, in the name of the Rashba, and the Rashba wrote in his novellae in the name of the Ritz Giat, for otherwise there is a difficulty from Rava against Rava. In any event, from there onward it is permitted while walking, because it is written, ‘and when you go.’ This requires study, for if so, what is meant by ‘and Rabbi Yehuda follows his reasoning’? In any event, the verse says, ‘and when you go.’ See Tosafot there, 16a, s.v. ‘ha.’ So too the Razah wrote that the same applies to the statement in the first chapter of Yoma, that one should not gesture, etc. But the Rif and all the poskim explained both cases as referring to the actual first parsha. One must say that each case is as it is, and there are three distinctions in the matter.
Walking on the way, etc. This is the language of the Yerushalmi cited above, and the Rosh, Rashba, and Tosafot cited above brought it.
