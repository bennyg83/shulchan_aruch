(3) And regarding shooting stars: on a shooting star one does not bless except once each night, and even if he saw another star running he does not bless again that night. And on a star that has a tail — if he does not see a different star afterward but it is the same one he sees every night — if he sees it within 30 days he need not return and bless. And regarding earthquakes — if some time passed between one tremor and another such that he diverted his attention from it, he must return and bless even if within 30 days; and if not he need not return and bless. The same applies regarding winds. Maharam ibn Chaviv there. Birkei Yosef note 3 Shaarei Teshuvah there. Chayei Shalom there. Kitzur Shulchan Aruch there. And see below note 14.
