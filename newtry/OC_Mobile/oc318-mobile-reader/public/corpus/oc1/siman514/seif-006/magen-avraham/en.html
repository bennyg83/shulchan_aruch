Lest he come to use it. He refers to the Rosh's statement that even if one removes it from there, this is not considered using the tree; rather, the prohibition is a decree lest one climb the tree in order to take it. This requires study, for Eruvin 32b states that when one takes his eruv from atop a tree he is using the tree. One cannot say that the Gemara's objection is that the Sages should decree lest he climb the tree, because the case necessarily concerns an eruv placed below ten handbreadths, so there is no need to climb. Moreover, the Gemara should have answered that this would be one decree upon another, since climbing itself is forbidden only lest one detach something. See what I wrote in siman 628 and siman 337, end of seif 1.
