For both of them. So that it not appear as fixing a vessel, for behold the wick has not yet been lit such that he would be making it into a vessel now; therefore we needed here that he require both of them, which is not so in seif 3 in the gloss, where it is already burning and he intends to shorten it so that it will go out quickly; see s.k. 8 there, and see Magen Avraham and Taz.
