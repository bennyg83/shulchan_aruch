One may place around it, etc. But after one has lit it, not so much: Beis Yosef and Maharil hold that ideally one should be careful; and my teacher in Bach permitted; but Levush cited Beis Yosef's view and it implies that he holds so. But the Rav in the gloss who wrote "and some interpret: to cut a wax candle, that even after it is already burning it is permitted to cut it by fire" all the more so to place around it something that prevents burning, so he wrote in Darkei Moshe, and so it is proven from the cross-reference; if so he disagrees with Beis Yosef, and this is not like the implication of Levush. However, if one cuts a burning wax candle by lighting it in the middle so that it will burn quickly, he should leave it so that the flame takes well to the wick so that it will tear of its own accord, and he should not tear it by force (Maharam).
But it is forbidden to set it there if the wind is already blowing; and likewise it is permitted to set it in sand so that it will go out, and the like (Maharshal, siman 85).
