Rashi, Sukkah 15b. So too wrote the Rambam, Hilchos Sukkah 5:2. If one transgressed and used them as s'chach, his sukkah is invalid, like one who used s'chach that is invalid according to the Torah. Shulchan Aruch HaRav, sec. 2. However, regarding a table and similar flat utensils, which according to all opinions are susceptible to tumah only rabbinically, if they broke, one can say that using them would involve a decree upon a decree, and therefore one may use them for s'chach. Mishbetzos Zahav, sec. 5; Bikkurei Yaakov; Mishna Berurah, sec. 8. See below, sec. 17.
