Uproot—see siman 178 corner to corner not considered change of place; same when sees his place; if ate in this room intends bless elsewhere in house may rely when that place not clean Magen Avraham see there.

Return—appears if far until returns food digested bless here Magen Avraham.

And R' Yehudah Weil and Rosh—see Taz who elaborated for halacha rule doubt blessings lenient; b'dieved all cases need not return if already blessed second place; if not yet blessed still return to place even accidental if possible and no delay from company waiting see there.
