If there is doubt whether there is excrement in a house, it is permitted to recite, for the presumption of a house is that it has no excrement. If there is doubt whether there is excrement in a refuse heap, it is forbidden, because the presumption of a refuse heap is that it has' excrement. But if there is doubt about urine, even in a refuse heap, it is permitted, because the Torah did not forbid reciting facing urine except facing an uninterrupted column; and after it fell it is forbidden only rabbinically, and in doubtful cases they did not decree.
