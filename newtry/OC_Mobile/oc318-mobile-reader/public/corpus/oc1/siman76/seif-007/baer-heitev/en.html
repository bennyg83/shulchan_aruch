It is permitted. The same applies if there is uncertainty in a house whether it is human excrement or dog excrement, in which case it is permitted; in a refuse heap it is forbidden. Shiltei Giborim in the name of Riaz. The Peri Chadash disagrees and writes that this is not persuasive, because here the case is different, since there is a presumption that a house contains no excrement. But where we see excrement and do not know its source, it is a Torah-level uncertainty. The Magen Avraham rules that we follow what is more common. If children are more common than dogs, it is forbidden even in a house. The converse is likewise true in a refuse heap: if dogs are more common, we attribute it to dogs. See there. According to the Peri Chadash, it appears to me that in a refuse heap, even if dogs are more common, since a refuse heap is presumed to commonly contain excrement and there is uncertainty whether it is dog excrement or human excrement, we rule stringently.
