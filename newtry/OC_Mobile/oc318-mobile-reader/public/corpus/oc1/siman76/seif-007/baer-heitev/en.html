Permitted. The same applies if there was a doubt whether it is human feces or dog feces — in a house it is permitted, and in a garbage dump it is forbidden — Sh"G, Ri'az. The Pri Chadash disagrees with him and wrote: it is not clear, for here it is different, since there is a presumption that a house has no feces; but if we see feces and do not know what it is, it is a Torah doubt. The Magen Avraham ruled that we follow what is common: if babies are more common than dogs, even in a house it is forbidden; and likewise the reverse in a garbage dump — if dogs are more common, we attribute it to dogs — see there. Per the Pri Chadash, it seems that in a garbage dump, even if dogs are more common, since in a garbage dump there is a presumption that feces is common and there is a doubt whether it is dog feces or human feces, we attribute it stringently.
