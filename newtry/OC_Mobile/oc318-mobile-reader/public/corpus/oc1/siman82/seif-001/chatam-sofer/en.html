In Magen Avraham, subsection 2—in Taharot chapter 3; see Mishnah 1 there. Nevertheless requires investigation, for it is different there: when it hardened, its primary impurity was nullified completely, for even if it later returned and dissolved, if it is the size of an egg intentionally it is pure; therefore it is reasonable that hardening helps. Not so with hardened excrement: if it thaws it may return to its former state, and it is possible it still stands in prohibition—requires study. And so the Talmud concludes in Menachot 58a: since one can cook them and return them to their quantity.
