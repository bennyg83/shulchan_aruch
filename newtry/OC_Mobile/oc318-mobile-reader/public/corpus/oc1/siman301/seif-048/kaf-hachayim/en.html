(א) There — between pierced etc. — Beit Yosef scribal error here; Shulchan Aruch written properly (Magen Avraham s.k. 15). See Taz s.k. 5 emendation Beit Yosef — see there. Bach "no one holds man liable pierced" — Magen Avraham: not forced; Taz: Bach wrote in vain, Beit Yosef and Shulchan Aruch not erring student, all coherent, needs emendation in Beit Yosef — see there. General rule: per time — if weekday custom carry thus and not ornament, way of carrying, liable; if not weekday way, exempt but forbidden as not ornament. Dispute which needle was way in Talmud times. If majority world not custom, even if locale does — exempt, opinion batel (Gemara 52; Magen Avraham; Eshel Avraham letter 19; Tosafot Shantz letter 17).
