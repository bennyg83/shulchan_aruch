6) [Seif 2] And strands of s'chach hang downward. This means that if we measure only up to the hanging strands, the open interior space is not more than twenty amos. Tosafos and the Rosh, first chapter of Eruvin 3b, and Sukkah 4a. So too wrote the Or Zarua in Hilchos Sukkah, proving this from Rashi's words; see there. So too wrote the Bach, Maamar Mordechai, os 1, Bigdei Yesha, and Machatzis HaShekel, s.k. 2, unlike Magen Avraham, s.k. 2. So too wrote Mishna Berurah, os 5.
