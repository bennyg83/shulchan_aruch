Seif 4: One should not bow, etc. Tosafos, Berachos 12b, s.v. kara, ‘and so it is stated,’ and so wrote the Rosh in the name of the Aruch regarding this Gemara and Yerushalmi. This is what the Rosh explained in chapter 5, siman 22, in the name of Rabbeinu Hai, ‘so that it should appear,’ and so forth. Tur.
