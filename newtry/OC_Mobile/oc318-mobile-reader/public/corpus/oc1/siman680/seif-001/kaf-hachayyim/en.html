1) [Seif 1] On Friday night he must place, etc. The same applies on a weekday, and he must be careful, for the rule that if it went out he need not attend to it applies only after the fact. Pri Chadash. So too wrote Shulchan Gavohah, letter 1, and Ruach Chaim in the name of Rosh Yosef; Mishna Berurah, letter 1. Shabbos is mentioned because greater care is required then. Alternatively, it is mentioned incidentally because of seif 2, which applies specifically on Shabbos. Mishna Berurah, ibid. See above, siman 673, letter 54.
