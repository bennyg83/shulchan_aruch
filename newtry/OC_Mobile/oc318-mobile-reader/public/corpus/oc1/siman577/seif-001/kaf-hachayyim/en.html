1) [Seif 1] In every place, if there is excessive rain, etc. The Tur writes as follows: We pray regarding every calamity that it should not come upon them, except regarding excessive rain, for we do not pray concerning an abundance of goodness. This applies only in a mountainous land, which requires abundant rain. However, in a low-lying land, where abundant rain is harmful, and moreover causes houses to collapse upon them, there is no calamity greater than this, and they pray concerning it. End quote. So too wrote the Levush. This is what the Shulchan Aruch means by saying, 'In every place, if there is excessive rain,' etc. Meaning, even in a mountainous land that requires abundant rain, if the excessive rain makes the ground muddy and prevents plowing, they sound the alarm, etc.
