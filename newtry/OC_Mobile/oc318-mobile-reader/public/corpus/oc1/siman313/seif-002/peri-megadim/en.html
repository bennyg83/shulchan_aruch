But if Taz — Rashi Eruvin 102a; and likewise nikmatz there it was asked — if one makes a handle what is the law? And it is simple that it is permitted; and according to Rif it refers to nikmatz that it is permitted when making a handle — if so all the more in a wall — or alternatively it is like nikmatz that making a handle suffices; and however for clarity so too he wrote; but in truth even when there is no handle — since from the outset it was made thus — permitted; and specifically when the threshold became damaged and pierces the ground anew — forbidden; but otherwise permitted — and all the more in a wall like this; and in Orach Chayyim letter 2 — a rod that one inserts in the wall — so is implied from Rosh — namely from what is written Shabbos 126 regarding distinguishing according to Rif between a rod and shards — for a rod with which one locks a house is like a garment, etc. — namely that one inserts it in the wall — not that one closes two half-doors or closes with it the frame and key; and for Taz it is somewhat difficult — a hole in the wall is comparable to a hole in the threshold — what difference between this and that; and a hole in the ground is possibly worse still; and possibly the threshold is not attached to the ground — requires further study:
