(9) There, and likewise opposite a skylight in a room — meaning a window in the roof; so mishnah chapter 1 of Ohalot and chapter 5 of Beitzah; therefore Ri'az wrote it is forbidden to check opposite a window — window means in the wall; Tur's view: even opposite a window in the wall is permitted, as Rambam; Magen Avraham s.k. 4; so Levush: even opposite window no candle needed; Chayei Adam note 4; Mekor Chayim annotation note 3; Machatzit HaShekel note 1; Rabbi Zalman note 4; if the window has a glass partition — all forbid checking opposite it — Magen Avraham there; Chayei Adam; Ateret Rosh note 3; Mekor Chayim; Rabbi Zalman; therefore one must open the window when checking opposite it without a candle.
