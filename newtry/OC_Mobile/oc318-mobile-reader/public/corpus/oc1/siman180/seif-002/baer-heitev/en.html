A whole loaf. This wording implies that if it is already lying on the table, it need not be removed. Taz and Be’er Sheva, chapter Chelek. See Magen Avraham, Shach to Yoreh Deah 178, and Yad Aharon. (See Eliyah Rabbah, who agrees with Mahari Weil.) Levush there in Yoreh Deah writes that those who set the table on Friday night with a whole loaf and leave it there all night should be stopped, for this practice certainly spread only from an idolatrous custom. See there. So too writes Nagid U’Metzaveh. Taz, there in Yoreh Deah and here, justifies and upholds the custom because it is done in honor of Shabbos. See there. Yad Aharon writes that his words are astonishing. See there.
