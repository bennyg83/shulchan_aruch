There it is explained that according to Rambam, if one intended to add an additional set of tzitzis and afterward cut away the latter set, the first set does not become valid, although it was originally made validly. This is because the prohibition of adding is an invalidity in the object itself. See what I wrote, with Hashem's help, in siman 12, letter 4.
