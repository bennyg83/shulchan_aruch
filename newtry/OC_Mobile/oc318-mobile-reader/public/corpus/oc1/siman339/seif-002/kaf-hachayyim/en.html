3) [Seif 2] One may not swim, etc. This is a decree lest one make a swimmer's barrel. Beitzah 36b. This is a woven reed implement shaped like a long barrel that is used to learn swimming. Rashi there.
4) There: Even in a pool in a courtyard. There is concern that one might splash water with his feet beyond four amos. Rashi, Shabbos 40b.
5) There: It resembles a river. It is included in the decree lest one make a swimmer's barrel.
6) There: If it has a rim around it, etc. This means wall-like raised sides on every side.
7) There: If it has a rim, it is permitted. Since it has a rim, it resembles a utensil. Swimming in a utensil was not prohibited, because there is no reason to decree in a utensil lest one make a swimmer's barrel. Bach; Taz, paragraph 1.
