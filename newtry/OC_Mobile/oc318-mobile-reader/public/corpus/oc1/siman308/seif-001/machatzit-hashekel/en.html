(s.k. 1) Forbidden, etc. — see siman 310 where it is explained that when it became a base for prohibition and permission it is permitted to move; however if the prohibition is more important than the permission — forbidden to move even if one can shake; nevertheless Magen Avraham proved that Rama's "forbidden to move" refers to the knife, for if about the case there are versions where permitted to move, namely when the permission is more important and shaking is impossible; if so Rama need not be vague.
