Forbidden to move it. Meaning: that scribes' knife is forbidden to move, for one might say that since it is stuck together with other knives he did not designate it — it teaches us it is forbidden; but the case with the knives is permitted to move, for it became a base for prohibition and permission — see siman 311.

That they are particular about it. But in a place where they are not particular about it — permitted, as written seif 3.

And he is particular about them. But if he is not particular about it — permitted; see siman 311 seif 2 [Beit Yosef], and see Ran: for any matter whose value is high — forbidden; and for a matter whose value is not high — only if he placed it in storage is it forbidden, as below.
