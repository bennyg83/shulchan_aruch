(2) There. Sukkah whose sun and shade equal from above invalid etc. — so Rashi; Ran and Maggid Mishneh agreed; so Rif and Rambam chapter 5 Sukkah as Bach explains see there; therefore ruled in Shulchan Aruch; Levush likewise. Razah wrote opposite: if equal above valid since below certainly shade greater because sun weak below; if equal below then above sun greater invalid — Bach, Raavad, Rosh, Tur. Rabbeinu Tam: one measuring air from above — equal valid standing like breached; standing below on ground looking up — equal invalid because wide air seems small like istra from distance — see there; Raash and Ran challenged Rabbeinu Tam as Bach explains. Bach wrote for halakhah be stringent like Rashi and like Eshel Avraham — therefore equal above or below invalid; also stringent like Rabbeinu Tam — standing below looking up even if seems shade greater — invalid — Bach, Taz. Knesset HaGedolah Hagahot Beit Yosef. Sefer Bigdei Yesha wrote Rashi also forbids standing below measuring up — forbidden to all; only if sekhakh visibly more than air may stand below inside sukkah and see if sekhakh predominates — no safek.
