If one said of a loaf "today it is unconsecrated and tomorrow it is consecrated" or "konام" — one may make a partnership eruv with it, since during twilight it had not yet certainly become consecrated and it was suitable while it was still day. But if one said "today it is konام and tomorrow it is unconsecrated" — one may not make a partnership eruv with it since it is not suitable until nightfall. A courtyard opening into two alleyways that made a partnership with each of them — it is permitted to carry between it and each of them, but it is forbidden to carry vessels that rested in one alleyway to the other alleyway through the courtyard. If it made no partnership with either of them: if it regularly uses both by entering and exiting through them on weekdays, it restricts both. If it regularly uses one and not the other, the one it regularly uses restricts while the one it does not regularly use does not restrict. If it made a partnership with the one it does not regularly use, the one it regularly uses becomes permitted on its own if they made a partnership among themselves. Similarly, if it regularly uses both and made a partnership with one of them, the other is permitted since it removed itself from it. If the alleyway it regularly uses made a partnership among themselves and the one it does not regularly use did not make a partnership, and it made no partnership with either — we push it toward the one it does not regularly use and it removes itself from the one it regularly uses so that the latter is permitted, since it loses nothing by this as it made no partnership with them, and others gain from it — we compel it on account of the trait of Sodom.
