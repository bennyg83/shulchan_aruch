Withered, some invalidate. Their reason is that only a moist, beautiful leaf saves from dryness. Some validate, because since withered is valid, it can save like actual moistness. See the Peri Megadim, who ruled that on the first day, which is biblical, it is proper to be stringent, for it is a Torah doubt; and on the other days, which are rabbinic, a rabbinic doubt is treated leniently.
