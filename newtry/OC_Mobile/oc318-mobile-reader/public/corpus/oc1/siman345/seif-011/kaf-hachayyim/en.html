11) There: Likewise, a trench ten tefachim deep, etc. Even when situated in a public domain, it is a private domain if it has this measure, as stated below in seif 11. If less than ten tefachim deep, it is a karmelis. If ten deep but not four wide, it is an exempt place. The same applies to a mound: if less than ten high, it is a karmelis, and if not four wide, it is an exempt place, as explained below in seifim 14 and 19; see there.
