Seif katan 2 Because of extinguishing. This is difficult, for this reason applies only regarding the prohibition of using some of it; in truth, even moving it is forbidden, since when it was burning the lamp and the oil were a base for a forbidden object. So it appears in the Talmud there, page 47, and since it was set aside, etc. If so, why did he need to say because of extinguishing? One may answer that the practical difference is that on Yom Tov too it is forbidden at least to use some of it for this reason, because when it was burning it was forbidden because of extinguishing, and since it was set aside, etc., therefore it is forbidden to use some of it; but moving it is permitted on Yom Tov.
