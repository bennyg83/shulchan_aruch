It is forbidden to move it. For at bein hashmashos it was forbidden to move it, as written in siman 276, end of seif 3; and since it was set aside at bein hashmashos, it was set aside for the entire day. If there is fear of non-Jews, it is permitted to move it after it goes out, Shiltei HaGibborim. But Rashi explained that a pressing circumstance means danger; this implies that where there is no danger it is forbidden.
The leftover oil. For while it is burning, it is forbidden to use from it because of extinguishing, and since it was set aside at bein hashmashos, etc., Ran. If so, with a wax candle on Yom Tov, it is permitted to use what remains, as written in siman 514, seif 3. However, in the Gemara there is also another reason: since it was set aside for its mitzvah, as written in siman 638 regarding sukkah decorations. If so, a mitzvah candle that was lit for the sake of Yom Tov and went out is forbidden for another use; for example, if it is made of oil, it is forbidden to eat it. See what I wrote in siman 263, seif 14. See Tosafot, folio 42, s.v. ve'ein ne'osin, etc., which implies like my words, that it is forbidden the entire day, since it was set aside at bein hashmashos, as written in siman 638.
