(ב) The oil is permitted — for while it is lit it is forbidden to use it because of extinguishing, and from the fact that it was set aside for bein hashemashot, etc. [Ran]. And if so, with a wax candle on Yom Tov it is permitted to use the remainder, as written in siman 514, seif 3; however in the Gemara there is another reason — since it was set aside for its mitzvah, as written in siman 638 regarding sukkah decoration; and if so, a candle of a mitzvah that was lit for Yom Tov and was extinguished — it is forbidden to use it for another use; for example, if it is from oil, it is forbidden to eat it — see siman 263, seif 14, and see in Tosafot daf 42 s.v. ve'ein ne'osin, etc., that it implies as I said, and all day it is forbidden from the fact that it was set aside for bein hashemashot, as written in siman 638.
