1) [Se'if 1] One who has no wine, etc. If one has only one cup, it should be used for Kiddush, because some maintain that Birkas HaMazon does not require a cup. If one has two cups, they should be used for Kiddush and Birkas HaMazon. If one has three, the first should be used for Kiddush, the Haggadah through Ga'al Yisrael should be recited over the second, and Birkas HaMazon should be recited over the third. Half of Hallel is then recited without a cup. Magen Avraham, at the beginning of this siman. Chok Yaakov, subsection 2, however, writes that on the first night, if one has only two cups, one should reserve one for the second night. See there. Eliyah Rabbah, subsection 1, challenges him. See there. Chok Yosef, subsection 1, likewise writes that Magen Avraham's opinion appears correct. Since the second night is observed only because of doubt, it is preferable to perform the mitzvah in its optimal form on the first night. See there. Ma'amar Mordechai, subsection 1, also agrees with Magen Avraham. Shulchan Aruch HaRav, subsection 5; Chayei Adam, rule 130, subsection 17; Mishnah Berurah, subsection 1, rule likewise. See above, siman 474, subsection 8.
