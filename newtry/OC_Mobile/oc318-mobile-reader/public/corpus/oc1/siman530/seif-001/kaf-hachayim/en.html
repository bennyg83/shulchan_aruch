(1) [seif 1] Chol hamoed — some melachot are forbidden, etc. Tur's view: melacha prohibition on chol hamoed is derabbanan; Beit Yosef brought several Rishonim — some hold derabbanan, some d'oraisa; and wrote that it appears melacha prohibition on chol hamoed is d'oraisa as implied in Chagigah (18a), only Torah entrusted to Sages to forbid melachot that seem fit to them, see there. So too Morenu Rama z"l in hagahah decided per Beit Yosef. So too Magen Avraham s.k. 1. Shulchan Gavoah letter 1. And it implies from here Maran z"l holds chol hamoed melacha is d'oraisa. So too Shulchan Gavoah there that below siman 541 seif 3 Shulchan Aruch rules like the view melacha on chol hamoed is from Torah — safek lechumra, see there. So too in Sefer Bigdei Yesha.
