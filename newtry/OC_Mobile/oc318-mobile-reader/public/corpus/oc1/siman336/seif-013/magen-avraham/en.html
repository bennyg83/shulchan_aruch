And the basket — permitted to take object from basket; basket itself forbidden — uses peg which is sides; basket on tree — forbidden to take from basket — uses sides (as in Gemara 155 and Eruvin 33); so Beit Yosef; Achiezer too; siman 328; Rashi this; Beit Yosef; if basket mouth narrow when taking object moves tree — forbidden (Gemara); leaning on tree — healthy permitted, weak forbidden (Yeshuot Shmuel, Beitza chapter 5 seif 6).
