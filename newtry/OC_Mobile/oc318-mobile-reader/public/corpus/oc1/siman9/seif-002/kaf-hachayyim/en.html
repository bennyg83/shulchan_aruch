6) [Seif 2] Linen tzitzis, etc. {Rama: And some say not to make linen tzitzis, etc.} This is the view of the Semak. Beit Yosef wrote the reason in the name of Maharai, of blessed memory: so that one not come to attach linen tzitzis to a wool tallis, because silk appears as a type of wool. And so wrote Magen Avraham, se'if katan 2; Shulchan Aruch HaRav, ot 3; Ben Ish Chai there, ot 4. And Beit Yosef further wrote there in that same name a second reason: because there is an opinion that linen tzitzis have no place from the Torah; see there. And if he has no option other than linen tzitzis, it is permitted to attach linen tzitzis to a garment of the other materials. Shulchan Aruch HaRav there; and so wrote Birkat Yosef, ot 2; but it is inferior; see the following ot.
