Across its width, in its minority. Meaning: around its circumference.
In its majority it is invalid. For it is as if [the part] was removed from this shofar; therefore if a measure sufficient for tekiah remained, it is kosher. And one may ask: since we reckon that which is above the crack as if completely cut off, what help is it that there is a [sufficient] measure in it; nevertheless that which is above the crack is an addition, and we say in seif 11 that if one added onto it it is invalid even of its kind. And one should not say that here it is different: since there is a crack in its circumference, what is above it is not called an addition, because we reckon it as if not attached, which is not so regarding adding onto it, where there is no crack at all; for nevertheless the sound emerges through that upper part, and the Merciful One said one shofar and not two shofaros. And in Beis Yosef he brought in the name of Kol Bo that also regarding adding onto it, if a [sufficient] measure remained in it, it is permitted; accordingly this is fine; but for the Shulchan Aruch, who did not rule so, it is difficult. And one may say that it is called an addition only when it was initially a separate piece, which is not so here, for it never separated.
