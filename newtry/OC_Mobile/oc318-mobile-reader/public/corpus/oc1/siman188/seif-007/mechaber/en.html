If one forgot to mention Rosh Chodesh — whether by day or by night — one says: Baruch shenatan Roshei Chodashim l'amo Yisrael l'zikaron, without a closing seal. This applies if one remembered before beginning HaTov veHaMeitiv. But if one did not remember until after beginning HaTov veHaMeitiv, one does not go back, because one is not obligated to eat bread in order to be required to recite Grace After Meals. Chol HaMoed has the same rule as Rosh Chodesh. If Rosh Chodesh falls on Shabbat and one mentioned Shabbat but not Rosh Chodesh, and did not remember until after beginning HaTov veHaMeitiv, one does not go back. If one also forgot Shabbat and remembered before beginning HaTov veHaMeitiv, one combines Rosh Chodesh with Shabbat and says: asher natan Shabbatot limnucha veRoshei Chodashim l'zikaron. If one already began HaTov veHaMeitiv, one returns to the beginning of Grace After Meals and mentions both Shabbat and Rosh Chodesh. Some say that if one forgot both Shabbat and Rosh Chodesh and remembered before beginning HaTov veHaMeitiv, one says asher natan Shabbatot limnucha veRoshei Chodashim l'zikaron and concludes with the Shabbat seal but not the Rosh Chodesh seal. {Rama: Gloss (Rema): It is possible that nonetheless one should say it within the other HaRachaman passages, as was explained above at the end of §187 regarding Al HaNissim — though perhaps there is a distinction, since Ya'aleh veYavo contains mentions of God's name and one should not recite it in vain. So it seems to me, and this is the custom.}
