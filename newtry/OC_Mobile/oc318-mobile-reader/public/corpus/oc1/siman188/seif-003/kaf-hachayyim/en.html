3) Maharshal writes in Responsa, siman 44, that one should not snatch and hasten to say, 'Who rebuilds Yerushalayim, Amen,' without a pause, because this would imply that it is the conclusion of Birkas HaMazon. Rather, he should pause briefly and then say Amen gently, so that it does not resemble the end of the blessing; see there. Mishbetzos Zahav, paragraph 1, cites this and writes that the pause should be within the time required for a short greeting, which is considered continuous speech. He should not pause at length, for then it would be an orphaned Amen; see there.
