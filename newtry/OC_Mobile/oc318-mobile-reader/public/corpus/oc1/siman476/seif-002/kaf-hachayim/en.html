(ב) There. On Passover nights — precise wording 'nights' to include second night practiced like first (Yefe Lalev Chayei Adam note 1). Regarding days: Beit Yehuda responsa 51 wrote where custom not to eat — both night and day, for we do not require specifically like actual Pesach eating; end; so I received from my teacher that roast prohibition for us is both first days night and day; so one should practice and lead others — see there; so page 108b siman 15. R' Chasdai David agreed, explanation of Tosefta chapter 2 Beitzah — see there; Bach Berakhai note 1 and in his book Mechabbar note 1; Chaim Sha'al section 2 siman 38 note 89; Ohr HaChaim note 1 — see there. However already wrote above siman 473 note 63 many Acharonim hold like Magen Avraham and so Mor uKetzia in Darkei Moshe: by day permitted to eat as written — see there. So too Tanna's wording 'Passover nights' implies even where custom not to eat it is only at nights; Shulchan Gavoah note 3: by day permitted everywhere for Pesach is not eaten except at night and we do not decree day due to night since main prohibition is only custom; so is custom — end; so Nahar Shalom note 2: evident from all poskim that by day permitted; wrote on Beit Yehuda's proofs they are not decisive and even if practiced it is not a binding custom; end: nevertheless do not lighten where practiced prohibition; still clear one should not institute prohibition in new city, especially where practiced permission, since matter depends on places — what is practiced is practiced — see there. Custom Izmir: not eat roast both Passover nights and first day only; second day they eat as rabbi of synagogues wrote in this siman — see there (R' Ovadiah Chaim note 1).
