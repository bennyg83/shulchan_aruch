Note: See my work Sefer HaChayim, where I concluded that although we rule that there is no permanent rejection with respect to mitzvos, where one actively rejected the object there is permanent rejection. See also what I wrote in my work on Yoreh Deah, fourth edition, siman 176, in Hilchos Challah, siman 324, explaining Rambam’s view there on this matter. There is support there for this ruling. See there and examine carefully; I discussed the matter at length there.
