If one has several four-cornered garments, all require <i>tzitzis</i>; if one wore them all without interruption and intended from the outset for all of them, one blesses only once; if one interrupts between them one must bless for each one; so too if one did not intend from the outset for all of them it is like interrupting between them. Rema: Likewise if one removed the first before putting on the second one must bless again (<i>Taz</i> 45). .
