Some say specifically where the agent lacks. See the Shach and Taz. These opinions do not actually disagree. The first view concerns a case where the agent did not disclose that he acted for another. The sale then remains valid for the principal if he wishes. The choice is therefore the principal's: if he is satisfied with the agent's personal responsibility, the agent must accept responsibility; if he is not satisfied with that responsibility, the agent must return his money. The second view concerns a case where the agent disclosed his status, in which case the agent can return the principal's money. The Taz writes that here the principal need not prove that he did not appoint the agent "for benefit or for loss," because a person is presumed not to throw away his money for nothing. This differs from the Sema. Regarding assumption of personal responsibility, we apply the presumption that a person does not waste money. See the Beurim. The agent can discharge himself only by paying actual cash, not by tendering appraised property, where he disclosed his status. If he lacks cash, the principal may compel him to accept personal responsibility. If the agent chooses instead to retain the purchase and seek reimbursement from the seller, the seller must return his money. If the seller lacks cash, the agent may collect land through beit din with the seller's warranty, but the seller need provide only enough land, as appraised by beit din, to equal the amount of the agent's money, not the entire field with full warranty:
