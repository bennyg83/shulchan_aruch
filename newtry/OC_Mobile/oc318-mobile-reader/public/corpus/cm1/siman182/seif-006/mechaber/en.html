If a principal gave money to an agent to buy land, and the agent bought it without a warranty, the agent acted improperly. The agent must take the property for himself without a warranty, as he bought it, and then sell it to the principal with a warranty, because the purchase was made with the principal's money and the agent must bear the warranty risk. Rama: This applies when the principal is satisfied with the agent's warranty and wishes to preserve the transaction. If he does not consider that warranty sufficient and wishes to cancel, he may do so. Some say this applies only when the agent cannot return the principal's money; if he is willing and able to return it, he may do so instead.
