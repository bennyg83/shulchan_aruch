Whether a robber who returned property requires the owner's knowledge has the same law as a thief, etc. In siman 355 it was explained that if the owner never knew of the theft, he need not be informed of the return either. That precise case does not usually apply to robbery, because ordinary robbery is taken openly from the victim and the victim knows of the taking. Rama therefore should have written simply that a robber must return with the owner's knowledge, following the distinctions stated in siman 355 regarding a thief. The Tur writes this in seif 3.
