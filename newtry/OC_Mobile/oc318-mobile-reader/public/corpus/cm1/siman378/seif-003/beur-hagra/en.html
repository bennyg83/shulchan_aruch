If it was, etc. See Beer HaGolah. This resolves Tosafos' question there, s.v. "and if you say," etc. The various answers are accepted together, and the case where the object became worm-eaten is exempt because that is a complete accident.
(Collected note) If it was not, etc. Even if it became worm-eaten, there was negligence at the outset. This is the meaning of "and if," etc., "or," etc. When the Gemara alternatively establishes both cases where it had not become worm-eaten, it does so only to make the ruling acceptable according to all opinions. The same principle applies even where it became worm-eaten. (End of note.)
