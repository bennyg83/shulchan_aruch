There was an opening, etc. Baer Heitev states that the same rule applies to a window. I heard that one rabbi ruled that if a glass window had been permanently fixed with nails around its perimeter, the owner may not later install hinges so that it can be opened and closed, because visibility through glass is not equivalent to direct sight through an open window; this requires study. Responsa Avkat Rochel, siman 121, discusses Reuven who wished to open a window toward Shimon's garden while placing glass panes before it. Shimon objected both because glass may eventually break, exposing him to visual intrusion, and because he might later wish to build opposite the window and Reuven could then object that his light was blocked. Beit Yosef answered that intact glass which fully blocks direct sight can constitute a partition against visual intrusion, just as even a reed partition may suffice; one need not fear that it will eventually break, especially if protected by a fine iron lattice. Shimon's second claim, however, is valid: creating the window could later impede his right to build. Accordingly, if Reuven has already set back four cubits so that this second objection does not apply, a genuinely sight-blocking glass partition would permit the window. It is clear, however, that the glass contemplated by Beit Yosef was not transparent glass of the sort through which one can see clearly. With modern transparent glass, visual intrusion remains, and the matter requires study.
