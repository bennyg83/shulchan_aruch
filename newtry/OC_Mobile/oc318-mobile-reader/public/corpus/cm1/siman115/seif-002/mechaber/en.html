If a creditor seized from a purchaser the portion due him from the field's principal value and half its appreciation, we examine the land remaining. If it remains useful to the purchaser, such as where a field retains an area sufficient to sow nine kav, or a garden retains an area sufficient to sow half a kav, they become partners in the land. If nothing useful remains because dividing it would give the entire remaining area an unfavorable designation, the creditor pays the purchaser its value. {Rama: This is if the purchaser wishes. Some say the same rule applies when the debt equals only the principal and not the appreciation, so that all the appreciation remains with the purchaser. This applies only if the seller did not make the field a designated lien. If he did, the creditor collects all the appreciation but reimburses the purchaser's expenditures. If the expenditures exceed the appreciation, he reimburses only up to the amount of the appreciation.}
