Tumim asks that since there is no minimum fixed amount, this too should be considered an obligation without a fixed measure and should therefore not be collectible from encumbered property. There is no difficulty. Tosafot in Ketubot 3 write that an obligation is considered without fixed measure specifically where neither creditor nor debtor can make the amount determinate, such as maintenance and support. But where the condition is in their hands and can be made determinate, it is considered fixed. Otherwise, if a document provides that if one performs a certain act he will owe one thousand, and if he does not he will owe one hundred, would we say that this is an obligation without fixed measure? Certainly not. Indeed, every condition would then be without fixed measure because it is possible that no liability will arise at all. Necessarily the distinction is as stated. The same applies here. Even if he gives him the false handwritten instrument, he becomes liable from that point, so the amount is within his power to make determinate.
