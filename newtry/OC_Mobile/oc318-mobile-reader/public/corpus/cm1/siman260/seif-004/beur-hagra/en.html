Reuven, etc.; if a deer, etc. As stated there on 11a: he saw, etc. The Gemara explains that in a guarded courtyard he need not stand beside it. See Tosafot there, s.v. 'she acquired,' etc.
Because they were, etc. See Baer HaGolah and the rule in chapter HaZahav. See siman 313, seif 3, that his courtyard, etc. This is Rambam's approach; see Baer HaGolah there. Rashi, however, explains there, s.v. 'in a courtyard,' etc., and all the commentators agree with him. This also appears to be the plain meaning of the Gemara, whose discussion is whether the courtyard is leased to the tenant. It answers that the case concerns the landlord's courtyard, a point the questioner did not doubt. Maggid Mishneh's proof is invalid, for the opposite inference is available: why did the Gemara not say, 'in a courtyard leased to the tenant'? Moreover, Rav Ashi says there, 'this teaches, etc.' Lechem Mishneh's reconciliation is strained. See 481.
But if, etc. If we rule like the Sages in Bava Kamma 114a that an ordinary theft causes the owner to despair, the thief acquired it. If we rule like Rabbi Shimon, it remains the owner's property. Either way it is not ownerless. Even ownerless property is not acquired by a courtyard while airborne where it will not eventually come to rest, as Rava states there. All the more so when it remains in the thief's hand.
