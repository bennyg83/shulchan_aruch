(In the Shulchan Aruch, seif 5: if they say, they read it before us, etc.) It appears to me that where validity depends upon the document having been read before them, it is not sufficient for beit din to ask the witnesses whether it was read before them. We must be concerned that from the litigants' words they may learn to lie and say that it was read before them. Rather, if they themselves volunteer that it was read, their statement is effective. If they do not say this on their own, the document is valid only if their oral testimony corresponds precisely, in which case there is no need to ask whether it was read before them because we presume that it was. Thus there are three rules: first, if they themselves say it was read before them, that suffices. Second, if they do not say so, their oral testimony must correspond. Third, if it is clear to us that it was not read before them, the document is invalid in every case.
