See above, siman 60, seif 6. There the Mechaber writes that we do not say, "It was found this way, therefore it was so originally." One can distinguish that there the defendant is alive and asserts a certain claim. There is still difficulty from siman 112, where Rama rules that the recipient bears the burden of proof. One can distinguish that the principle, "It was found this way, therefore it was so originally," applies only to movables. With land, which remains permanently in one place, the principle does not apply. Sema. See above in siman 60 in the Beurim, where I discussed this at length and clarified the various distinctions properly.
