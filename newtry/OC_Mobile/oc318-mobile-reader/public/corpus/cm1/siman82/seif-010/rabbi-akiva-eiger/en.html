[Shulchan Aruch] And if he admits, he must return it. Note: The Rambam first writes that the debt is fixed interest or rabbinic interest. One must explain that when he says that if the creditor admits it was interest he must return it, although rabbinic interest is not recoverable through beit din, this is because the borrower did not willingly pay the rabbinic interest, but was compelled to pay only because the creditor was not believed that it was interest. Since it was not given voluntarily, the creditor must return it. See Responsa Tashbetz, part 4, second section, siman 14.
