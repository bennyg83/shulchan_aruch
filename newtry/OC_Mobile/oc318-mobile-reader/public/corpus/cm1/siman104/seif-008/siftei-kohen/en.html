If there were creditors against him, etc. See responsum Menahem Azariah, siman 129, and responsum Mahari ben Lev, siman 95. The Ran writes that the rule that there is no priority among them applies only according to the view that an oral loan has no right of priority. This requires study, because the Mechaber rules below in seif 13 that an earlier oral loan takes precedence over a later written loan when collecting from unencumbered property, contrary to the Ran. How, then, can he rule here that there is no priority among them? This requires study.
