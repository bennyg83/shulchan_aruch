(Shach, seif katan 6, end of the passage) And so wrote Tosafot Rid in Kiddushin. Note: This is not correct. Tosafot Rid wrote this only concerning misuse of sacred property, where the rule for inadvertence follows the rule for intentional violation, analogous to those liable for a sin-offering: whenever intentional conduct incurs karet, inadvertent conduct incurs a sin-offering. So too here, one who is liable intentionally to a prohibition or death penalty is liable inadvertently for a me'ilah offering. See there. It is explicit there that regarding other cases, where this rationale does not apply, Tosafot Rid agrees with Tosafot that if the agent acted inadvertently there is agency even for a transgression.
