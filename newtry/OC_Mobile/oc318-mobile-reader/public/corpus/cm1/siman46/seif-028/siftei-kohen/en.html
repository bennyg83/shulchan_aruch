And one of the authentication judges was found unfit, and so forth. See what I write below in seif 30, seif katan 76.
They should cut it off, and so forth. This is not necessarily literal. It means that the authentication is invalid and, being unnecessary, should be removed, perhaps because a later court might rely upon it without knowing it is invalid. If it cannot be cut off, such as where it is written on the reverse of the document opposite the text, it need not be removed. Any concern that it might be relied upon can be addressed by drawing ink lines through the authentication. Alternatively, perhaps we do not suspect that a later court will rely upon it. In any event, the underlying document is not invalid merely because the authentication was not cut away. A responsum printed among the Ramban’s responsa, at the end of siman 91, states similarly that although the authentication in the case before him was not properly made because testimony was received without all three judges present, only the authentication is invalid and regarded as nonexistent. The document, which was otherwise valid, is not invalidated. Even if a later beit din might rely on that authentication, the document does not become invalid on that account. The Sages said that an instrument internally tainted by forgery is invalid only in a case comparable to a document whose signatories are unfit. Nevertheless, initially it is proper to correct the matter by drawing ink lines through the authentication, because whenever correction is possible we correct it.
