On condition that you return it to me, it is not consecrated. Rosh writes in Kiddushin concerning a borrowed ring that at minimum the lender could make it a gift on condition of return. The recipient can then transfer it for kiddushin and afterward reacquire it from the woman and return it, or return its value. Returning value can count as return where the donor's purpose is economic benefit rather than affliction. Rosh adds that if one says, "This ox is given to you on condition that you return it to me," and the recipient consecrates it and returns its value, the consecration can stand because the donor can buy another comparable ox with the money. That is called returning something suitable to him. Yet elsewhere Rosh writes that a gift on condition of return can remain a valid gift even though the recipient cannot consecrate it. This seems difficult if consecration followed by payment of value can in fact satisfy the condition. Rabbi Avigdor Kohen Tzedek resolves the point by saying that in the etrog case consecration can stand only if the recipient redeems it and returns the required value. The statement that "if he consecrated it, it is not returned" means that consecration without redemption does not satisfy the condition. Rosh's own law of an etrog is stricter, because for an etrog the donor can require return of the actual etrog rather than its value. Rosh cites Baal HaIttur that return of money is not enough where the particular etrog is needed. Therefore the etrog is a valid example of a gift with restrictions even though consecration cannot practically satisfy the return condition merely through payment. Tur and Shulchan Aruch in Even HaEzer rule that one who receives a gift on condition of return can use it for kiddushin and then reacquire it from the woman or return its value. See what I wrote below in seif katan 7.
Only something suitable for him. Nimukei Yosef writes that when a donor says, "on condition that you return it to me," he means that what is returned must remain suitable for him. Therefore, if the recipient sold, gave away, or consecrated the object and then purported to return it in a state in which another party could later take it, the condition was not fulfilled. He cites a dispute where one gave a gift on condition that it be returned at a fixed time and the recipient subjected it to a creditor before returning it. Some say the lien remains effective because the recipient was complete owner while the object was in his possession, and the creditor can collect even after the return. Ritva disagrees, because if the creditor later takes it, the donor did not actually receive something suitable for him. The earlier gift therefore fails and the lien cannot stand. In my view Ritva's conclusion depends on language requiring return of something "suitable for me." If the donor merely says, "on condition that you return it," without the word "to me" or another indication of suitability, then physical return can satisfy the condition even though the prior lien remains. In that case the creditor can later collect. This distinction also prevents contradiction between Ritva here and his earlier statement in Kiddushin that if the recipient subjected the gift to a creditor, the lien can stand after return. The earlier discussion can be understood where the donor did not require the returned object to be fully suitable for him. Nimukei Yosef's wording concerning sale or gift to a third person is more difficult. It suggests that if the recipient sold or gave it away first and then later returned it, the condition fails because the donor does not receive something suitable. I hesitate about this. Even without special "to me" language, once the object has been fully sold or given to another, a later physical return by the first recipient may not count as return at all because the object is no longer his to return. Consecration is different from sale in some respects. This requires study.
If he stipulated that one particular object be given, its value can be given instead. Terumat HaDeshen explains that this is only where the object is no longer physically available. In ordinary monetary conditions, unlike a get where the exact condition can be indispensable, if the donor's purpose was simply economic benefit and the object no longer exists, returning its value can satisfy the condition. But if the object itself is still present, the actual object must be given. The Gemara says that even Rabban Shimon ben Gamliel's rule allowing value instead of a cloak applies where the cloak is no longer present, not where it remains available. The reason is that when the object is present, the donor expressly conditioned upon that object. Had he wanted money, he could have stipulated a monetary amount. His choice of the object shows that the object itself was important to him. Rosh's statement that a gift on condition of return can be used for kiddushin and afterward its value returned fits this. Once the recipient has sold or given the object to the woman, it is no longer in his hands. It is treated like an object no longer present, and we infer that the donor prefers its value rather than total failure of the condition. This applies where the recipient actually sold, gave, or fully consecrated the object so that another person or consecrated property acquired it. If he merely swore or gave a handshake pledge to give it to another, no transfer has occurred. The object remains fully in his hands and must itself be returned. The same applies to contemporary charitable dedications. A verbal declaration of charity to the poor does not itself transfer ownership to the poor as Temple consecration does. It creates a vow obligation. Since the object remains legally in the recipient's hand, it is still "present" and the condition requires return of the actual object. This also explains why Tur and Shulchan Aruch state simply that one who received property on condition to return it cannot consecrate it in a way that defeats return. Rosh's statement that value can sometimes be returned concerns true Temple consecration or another completed transfer, where the object is legally no longer present in the recipient's hands. Our ordinary charitable dedication does not effect that proprietary transfer. Therefore the actual object must still be returned.
