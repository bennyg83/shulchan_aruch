If one claims, 'I lent you one hundred,' and the defendant says, 'You have in my possession only fifty zuz, which you gave as payment for a specified object that still exists,' or, 'You lent me the money against that object on condition that you would collect only from the object itself,' some say he has not admitted the matter claimed. The same applies conversely when the claimant says that the defendant holds a specified object designated to secure one hundred, while the defendant admits only an ordinary loan of fifty zuz. The defendant is exempt both from payment and from a Torah oath; he takes a heses oath and is exempt.
