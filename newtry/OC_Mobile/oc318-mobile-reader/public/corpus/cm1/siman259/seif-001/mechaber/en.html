Returning lost property, and from what place one is obligated to return it. It contains nine seifim.
One who sees lost property belonging to a Jew must attend to it and return it to its owner, as stated, "You shall surely return them." If he takes it intending to steal it before the owner has despaired, he violates the command to return it, the prohibition against stealing, and the prohibition against ignoring lost property. Even if he later returns it, he already violated the prohibition against ignoring it. If he took it before despair intending to return it, but after despair decided to steal it, he violates only the positive command to return it. If he waited until after despair and then took it, he violates only the prohibition against ignoring it.
