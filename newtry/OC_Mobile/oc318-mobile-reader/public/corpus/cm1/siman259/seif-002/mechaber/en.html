The obligation to return lost property applies only when the item was lost in a place from which one is required to return it, when the circumstances reasonably indicate that it was lost rather than intentionally placed there, when it is worth at least a perutah, when it has an identifying mark either on the object or in its location, when the finder would trouble himself over such an item if it were his own, and when it belongs to a person whose lost property one is obligated to return. If any one of these conditions is absent, there is no obligation to return it.
