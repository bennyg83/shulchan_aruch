Seif 30: Or Shimon released Levi. The text is difficult. If Shimon informed Levi when forming the partnership that the money belonged to Reuven and that Shimon had no independent interest in it, Shimon's later release of Levi plainly cannot help. If Shimon did not disclose this, why should the release not be effective? Levi can say to Reuven, “I accepted the money from Shimon on the understanding that if he released me, I would be released,” similar to the law of an agent who deviates from instructions. The continuation, “he released,” also seems grammatically to refer to both clauses, though substantively it belongs only to the first. The Beit Yosef cites the Ittur as reading: even if Reuven released Shimon from an oath, but Shimon did not release Levi from an oath. This is coherent. Reuven may say, “I released only Shimon, not Levi who comes through Shimon,” since Levi still owes Shimon an oath. But if Shimon actually released Levi, the release certainly takes effect. The Sema's interpretation severs the Mechaber's ruling from the Ittur, which is plainly its source. The text should therefore read, “and Shimon did not release Levi,” exactly as in the Ittur. If Shimon did release Levi, it is effective even where Levi received the funds directly, not only in a formal agency. The Sema's question from seif 10, that a partner has no authority to form a new partnership with another, is no question. Here Shimon's partnership with Levi was formed with Reuven's consent. The only issue is release from an oath.
