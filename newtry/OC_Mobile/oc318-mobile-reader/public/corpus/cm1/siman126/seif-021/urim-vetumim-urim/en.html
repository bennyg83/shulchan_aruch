Through writing. Since maamad sheloshtan does not work through an ordinary agent, all the more so it does not work merely by written instruction, because there is no actual three-party standing; the giver is speaking only to the custodian. Rivash. It appears the same is true through writing of the recipient, and indeed that is weaker. Shach. Maharit, part 1, siman 15, holds that maamad sheloshtan may work through the borrower's agent if the borrower's money is already in that agent's hands on the borrower's behalf. This requires study.
