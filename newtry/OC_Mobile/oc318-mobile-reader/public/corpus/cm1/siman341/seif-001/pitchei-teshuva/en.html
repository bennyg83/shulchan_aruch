Urim VeTumim, above siman 63 seif katan 4, writes that if one lent an object for a particular use, such as an axe for chopping, he must at least allow the borrower one opportunity to use it for that purpose, because with respect to that use it is as though he lent it for a defined term. See there. Netivot HaMishpat writes that so long as the lender has not demanded its return, the borrower may continue using it and remains liable for unavoidable accidents indefinitely. See there.
