He mentioned to him only defects that it actually had. This requires study. The implication is that if the seller also mentioned visible defects that the item did not have, the sale could be considered mistaken. Which defects are meant? If visible defects, the Tur and Mechaber already wrote that whether all or only some of the defects mentioned are found, there is no mistaken sale. If hidden defects, the language "even if it had all the defects" implies all the more so if it had only some. We must therefore explain that the reference is to visible defects in a case where the article also has many hidden defects. If the seller had mentioned visible defects that were not present, the purchaser could say: Just as some of the visible defects you mentioned were not actually present, I assumed that some of the hidden defects were likewise not present. If afterward all of the hidden defects are found, the sale is mistaken. The word "even" is precise according to this explanation. The Gemara and poskim also say that the seller showed him the visible defect. The novelty is that although he actually showed the visible defect, and there are many additional hidden defects, the transaction is still not mistaken. One might have thought that by taking the trouble to show the visible defect, the seller implied that if there were additional defects he would likewise have shown them. The ruling teaches otherwise.
