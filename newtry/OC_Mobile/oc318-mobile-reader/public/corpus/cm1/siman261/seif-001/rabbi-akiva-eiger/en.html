[Shach, subparagraph 2] See below, siman 263. Note: This implies that the Shach means that just as there, once one begins returning a lost object he must continue until it reaches the owner’s possession, so too here. However, Or Zarua, citing Ritva, distinguishes the cases. Since here the obligation arises only from preventing loss to land, once he removes the animal from there and places it in a grazing area, that is sufficient. The rule that once one strikes or begins handling an animal he becomes obligated to return it does not apply. That rule applies only where the obligation is ordinary return of a lost object itself, not merely loss to land.
