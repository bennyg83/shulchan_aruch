Rental of movable property, etc. Since the body of the object remains the owner's, if Reuven rents a movable object to Shimon, Shimon pays the rent, and the object has not yet been pulled into Shimon's possession, neither party may retract from the rental. The Sages' concern that the seller might fail to save the object from fire because he could tell the buyer to save it does not apply. Shimon has only temporary use, while ownership of the object remains with Reuven, so Reuven will save it.
