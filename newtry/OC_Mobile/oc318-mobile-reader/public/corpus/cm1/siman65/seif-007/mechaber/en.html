Likewise, if the borrower has sufficient unencumbered property to cover the debt and admits liability, a found document is returned. If it is found on the day it was written and bears an authentication endorsement, it is returned when the debtor admits liability. Some say the rule permitting return when found on its date applies only when the borrower is absent; if he is present and says, 'I paid it, and it fell from me,' it is not returned.
