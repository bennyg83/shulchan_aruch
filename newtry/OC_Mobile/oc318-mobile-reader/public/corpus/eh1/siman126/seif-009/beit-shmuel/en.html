He should not write "vedein." This implies "din," judgment, namely that he divorces only if the law requires it; if the law does not require divorce, it is not a get. "Iggeret" with a yud according to Rashi is an expression of a roof; according to this it changes the meaning of the word. According to the Rambam it implies "zonah," as though if you committed zenut it should be a get and if not it should not be a get. If so, it changes the get and is invalid even in pressing circumstances. What is written in seif 22, that if he wrote the yuds that we said not to write it is an invalid get, implies the Rambam’s view. Tosafot wrote that one must write "ve'iggeret," not "iggeret" without a vav, because otherwise it implies he is merely sending a letter, not a bill of divorce. The dalet of "vedein" should be read with tzeirei. "Vedein" should be written at the beginning of the line so that "sefer teruchin" until "piturin" is on one line and not on the last line. Seder Maharam Padua.
