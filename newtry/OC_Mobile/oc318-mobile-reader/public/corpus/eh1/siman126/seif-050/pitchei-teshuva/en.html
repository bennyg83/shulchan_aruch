Extra letters. See the responsum of my grandfather Panim Meirot, part 3, siman 47, regarding a get brought by an agent where in the word tzviti, which should be written with two yuds, it was written with three yuds, meaning that he added a yud between the tzadi and the beit. He responded: I see no concern in this, because the meaning does not change because of it, etc. So too if a yud was written in antati, although the Shulchan Aruch wrote above, seif 36, that one should write it without a yud between the alef and nun, we have not heard or seen in any decisor to invalidate the get because of this, etc. Likewise regarding piturin, which some write full and we customarily write deficient, see above, seif 12 in the gloss and what I wrote there, s.k. 22, and teruchin and shevukin, where they agreed to write it missing a yud, no decisor would think to invalidate the get if he wrote it with a yud. So too regarding minai, which the custom is to write without a yud after the mem, the Rama wrote above, seif 60, that it is not invalid bedieved. Although there is some change in language there, how much more so here, where the language does not change at all, that even without igun one should validate. These are his words. See there.
