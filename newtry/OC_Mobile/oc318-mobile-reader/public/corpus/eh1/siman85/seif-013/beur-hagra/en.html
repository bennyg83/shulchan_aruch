(א) Nichsei melog, etc. As above.
(ב) And if they are, etc. The Mishnah, 79a: money, etc.; detached produce, etc.
(ג) And if it is, etc. There in the Gemara: it is obvious, etc. See Be'er HaGolah.
(ד) Whether, etc. So too Rashi wrote. See there, s.v. "it is obvious," etc.
(ה) And we do not buy, etc. According to the explanation of Rabbenu Tam there in Tosafot, s.v. "the rule." Rabbenu Tam has the version of Rabbenu Chananel and explains, etc. According to Rashi’s explanation, it is difficult, because he explains, etc. The Rosh appears to rule according to both versions. He wrote that according to the first version, this is the explanation, etc., and according to the latter version, this is the explanation. So ruled the Tur.
(ו) Although there is no, etc. So the Rif wrote there, unlike Rashi, s.v. "he eats," etc. So too the Rosh, who challenged the Rif and ruled like Rashi. They follow their own approaches, for they hold like the first version. See Rashi, s.v. "and some say," etc., and likewise the Rosh, as above. But the Rif and Rambam hold according to the explanation of Rabbenu Chananel, as above.
