Tallit. Unless partition barrier; then even if lit permitted if darkened with tallit as Orach Chaim; and if moonlight through window permitted — so Shelah; however needs darkening tallit; if candle in another room shines here permitted as Orach Chaim siman 271; possible needs darkening tallit; house with books forbidden; if partition gatier before books ruled Sha'arei Ephraim siman 119 forbidden because forbidden relations depend on seeing and books still seen; however any cover suffices partition not needed — Beit Shmuel.
