Any smudge. The reason is concern for forgery. Darkei Moshe wrote that one should be careful that no drip or dirt fall on the parchment, because when one writes over it, it appears erased. If rain falls on the writing, the get should not be given, for it turns black and is like something that can be forged. One should not write over an erasure for the same reason. Although by strict law it is permitted to write on something that can be forged, as written in siman 124, namely where the delivery witnesses are before us, nevertheless ab initio one must be careful, lest the delivery witnesses die. Likewise, if a fly dragged ink from a letter, one should not erase it; there should be no erased matter between word and word or between letter and letter, because that is something that can be forged. Therefore one does not write over something scraped. I have already written that in a case of agunah it is valid. Darkei Moshe wrote that if it was punctured beside the letter and not in the letter, it is valid.
