And he likewise said, etc. Meaning that he wrote, "So-and-so divorced so-and-so," and wrote the entire get formula for each one. The Derishah writes that he need not write the entire formula for each; rather, for each he writes until "to you," and at the end finishes the whole formula. Then it is not two women leaving with one get, because he wrote for each one the essential get, and the rest of the formula is only additional wording. It appears to me that this law depends on what constitutes the toref of the get. Everything that is part of the toref must be written for each one. I wrote above that "you are hereby permitted," etc., is also the toref of the get; if so, he must write the whole get for each one. If he wrote one formula for all of them, the get is void, because biblically it is two women leaving with one get. So wrote the Tur in the name of Ramah. The Rambam’s words can be explained this way, and this is the Mechaber’s language. So explained Rashach. The Bach’s explanation is not necessary.
And if there are no delivery witnesses. So wrote the Rambam, implying that even if it is known there were no delivery witnesses, it is valid. He follows his own view that even without delivery witnesses it is valid, as written in siman 133. According to the Rama there, if there are no delivery witnesses it is invalid. One must therefore explain here: if there are not definitely delivery witnesses, but it is uncertain whether there were, the get is valid, because we say there certainly were delivery witnesses since signing witnesses are on it. What is written that it should be given to each one before delivery witnesses means lechatchilah he should deliver to each before delivery witnesses. If we do not know whether it was delivered before delivery witnesses, it is valid, and we presume there were delivery witnesses.
