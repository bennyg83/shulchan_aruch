(ב) His name was lost. This means that the majority call him only by one name. Levush. This is specifically if the minor name was lost. But if the major name was lost, both names are mentioned. If it is doubtful, meaning some people call him by this name and some by that name, they write only the major name and do not write both names, because perhaps the major name is primary and it would be a change. But in the reverse there is no concern, for the major name is not displaced. Levush. Regarding the name of a river or city that is pronounced with a soft kaf, although in these countries we pronounce chet like a soft kaf, nevertheless one should write a soft kaf, because in some countries chet is pronounced like heh. Terumat HaDeshen, siman 231. See the end of siman 129. A river or city whose name is like two names, such as Regen-Shpurg and the like, is one name.
