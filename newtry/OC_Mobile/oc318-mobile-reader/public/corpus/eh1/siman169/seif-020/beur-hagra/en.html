(א) Some say that one should not, etc. As stated there, 102a. But from there the opposite appears, as written: What is the reason? If we say, etc. See Rashi, s.v. i hachi, “even,” etc. Rather, it is only a lechatchilah stringency.
(ב) He should be careful to sew it, etc. From what is written at the end of the first chapter of Yom Tov, where it mentions pegs. See Rashi there.
(ג) And they make, etc. This is how the text should read. Perhaps they explain “if,” even, as meaning: if they made it in this form, even bedieved it is invalid, but only when it is not made this way. Likewise, they did not raise this question in such a case, because it is certainly invalid, since he removes both at once. They questioned only where he removes one. Also, the case of covered with leather is not difficult, because there it is sewn and appears as one, unlike here. All of this is very forced, for it does not appear so at all.
