Get from each, etc. If condition — betrothed to first alone; if retraction — to last alone betrothed; but middle — kiddushin in any case — this is Abaye's reasoning and so Rosh; only Rambam is stringent on all to require get from them lest first was retraction and others condition — automatically middle's kiddushin are fine (kiddushin); that which is written and after ten days — unnecessary; even if betrothed without specification since no betrother after him except via others cited; see end of siman what I wrote on Beit Yosef's words.
