(Siman 324, Shach s.k. 18) That the same applies if it became mixed. One must examine this, for the Rash wrote: this is not like separating from what is obligated for what is exempt, because the leaven is not nullified in the dough, since taste is like substance by Torah law. So too the Rosh wrote in a responsum in the name of the Rash regarding our Mishnah, that it is not comparable to Menachot 31, for there, since it became mixed, the tevel is nullified by Torah law; but in the case of challah, since leaven is made for taste, it is not nullified. If so, this is specifically leaven that became mixed in dough. But with dough mixed into dough, where by Torah law it is nullified, one cannot separate from elsewhere. See the Shach nearby, s.k. 24, and examine carefully.
