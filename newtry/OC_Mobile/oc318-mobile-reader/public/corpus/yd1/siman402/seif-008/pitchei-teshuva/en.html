**All his days.** Be'er Heitev of Mahari"t; see Taz there — meaning Taz there s.k. 3 disagrees, wrote not called vow path unless intends always forever — lenient did not lose; especially one distressed — see responsa Chut HaShani siman 66 — wrote when yahrzeit first on erev Shabbat need not complete when also later on erev Shabbat; but when falls weekday must complete — see there; also even when first weekday, if later erev Shabbat not complete since presumably acceptance not on erev Shabbat etc.; see responsa Nachalat Shivah siman 58 — also when weekday, if later erev Shabbat need not complete; as first yahrzeit on erev Shabbat so all his days; as Rema wrote not like those who err all depends on first yahrzeit after twelve months — rather on first yahrzeit on erev Shabbat he speaks — see there; see responsa Chinnuch Beit Yehudah siman 23 did not write thus — see there. See Pri Megadim Mishbetzot wrote to be lenient when first (meaning after twelve months) on erev Shabbat; his view even if occurs weekday not complete since generations weak — see there.
