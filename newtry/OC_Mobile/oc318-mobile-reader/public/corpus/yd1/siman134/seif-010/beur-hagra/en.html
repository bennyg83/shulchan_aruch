It fell, etc. As stated there: We learned, yayin nesech, etc., because, etc.; wheat is different, etc., unlike barley and lentils.
(Likut) It fell on lentils, etc. This means when cold, as is evident from 'he should rinse them,' etc., and 'if,' etc. When hot, it is entirely permitted, as stated there on 68a and 68b regarding wine that fell, etc. (End of Likut.)
(Likut) On lentils and barley, etc. These are Rashba's words. Ran writes likewise there, but in both places mentions only barley. (End of Likut.)
If he transgressed, etc. As stated in Pesachim 40a: Rava said it is forbidden, etc.; not only, etc. All the more so when they soaked for a long time. Even according to the conclusion there that moistening grain is permitted, that is because one is actively occupied with the moistening.
(Likut) If he transgressed, etc. Even during the moistening process we are concerned regarding chametz in the chapter Kol Shaah, 40a, where it is taught: One may not moisten grain, etc. All the more so if it soaked for a long time. Rashba and Ran. (End of Likut.)
