That is, etc., whether, etc. As in the expression, “Konam, a sukkah,” etc.
Whether, etc. This follows from the statement on 15b, “But he is obligated,” etc. The Gemara does not object that he vowed to nullify a negative commandment.
And there is no distinction, etc. This follows all the more so regarding a prohibition that comes through one's own declaration, which does take effect. See what is written below. It was necessary to state this only below, not here.
But concerning, etc. See Tosafos, Shevuos 20b, s.v. “For when,” and the continuation, “for behold,” etc. The phrase “whether regarding its fulfillment” refers to Tosafos' question there, where they write, “However, according to Rabbi Yehudah ben Beseira,” etc. See also Tosafos there, 27a, s.v. “To fulfill,” etc. The Gemara states in Makkos 22a, “Let it also count,” etc., “he is already sworn,” etc. If the present view were correct, it should likewise count a prohibition created by konam.
The same law applies, etc. See Tosafos, Nedarim 17a, s.v. “Is there a vow,” etc., and their answer, “It may be said because,” etc.; Ran there, s.v. “An oath,” and s.v. “According to Rav Huna,” etc.; and Ran 18a, s.v. “With what are we dealing,” where he writes, “I have seen some,” etc. Ran likewise writes this in the name of Razah in chapter 3 of Shevuos. He first distinguishes between a prohibition that comes through one's own declaration, etc., and then returns to explain as stated here.
Such as, etc., and likewise, etc. This requires study, for the Yerushalmi in the first chapter of Nedarim states that one is liable for each and every oath. Rabbi Yochanan says that this applies only where there are five loaves, but regarding a single loaf, once he has imposed an oath upon it, he has rendered it like neveilah from that point onward, etc. Ran cites this there. Rashba, responsum 615, answers that a vow takes effect upon an oath by virtue of an added prohibition, since an object-based prohibition has now been added to it. It therefore requires study why the ruling here is the reverse. Regarding a nazir, however, it is understandable, since that prohibition also rests upon the person, as stated above at the end of siman 206.
Meaning, etc. See Tosafos there, s.v. “Konamos,” etc.
And the vow, etc. As explained above. He repeated the point only because the question addressed this matter.
