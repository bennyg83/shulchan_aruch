It releases. Shach: even blood in eye no "as it absorbs so it releases" (siman 69, 70) — heart shia helps as emission; if after salting fell to gravy permitted — shia did not absorb; Hagahat Shaarei Dura: enclosed blood dries in salting/roasting — emission blood.
Exited. Shach: per Mechaber only if not salted first; if salted — only sixty against blood in heart — enclosed blood in one place can be estimated like veins; requires further study. Taz rules practice stringent: even salted need sixty entire heart; proof Maharil.
Itself. Sometimes blood in heart cooks and dries entirely in cavity, does not exit; not forbidden because heart becomes nevelah — Maharai shia helps.
Heart. If heart cooked with fowl and piece has sixty — still peel since salted with it forbidden peel-thickness; proves Rav even if heart salted first estimate entire heart — Shach.
To be lenient. Shach: Maharshal like "some stringent"; main Rav; Bach so practice; l'chatchila do not salt or roast heart with meat — need peel; stringent also require removal if roasted.
And peel. (Then all poskim agree salting only peel, but we stringent sixty — Torat Chatas.) Shach: even if heart not stuck but salted with meat need peel; unlike liver siman 73; here blood in eye — peel; roasting too — not like Bach.
Itself. Where we say on heart itself "as it absorbs so it releases" — so meat with it.
Above. Even if closed above, tear after salting/roasting helps; if open above tear well — open above not torn; if cooked so forbidden — Shach; Taz: if on mouth where blood flows — called torn.
