He may remove some ink, etc. This does not constitute weakening a mitzvah object. It is unlike lighting an ordinary lamp from a mitzvah lamp, for there the second lamp draws from and weakens the first. Here, once the word has been written, it is not weakened when some ink is removed merely so that it will dry more quickly. End quote from a responsum of the Rosh. This implies that one may remove ink even from a Divine Name, and that from the standpoint of weakening a mitzvah object one could even use that ink for mundane writing. Nevertheless, although there is no concern of weakening the mitzvah, there is still a concern of disgracing the mitzvah if one takes ink from a Divine Name to write another word, or from a Torah scroll to write something mundane. According to the view that one may not light an ordinary lamp from a mitzvah lamp because this disgraces the mitzvah, as explained in Orach Chaim, siman 674, the same applies here. It is permitted only when the ink is removed so that the writing will dry quickly, and not in order to use the ink elsewhere. This appears correct to me.
