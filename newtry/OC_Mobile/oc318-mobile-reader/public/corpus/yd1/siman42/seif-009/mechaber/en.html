A kernel found in the gall bladder: if it was like a date pit that has no sharp point — permitted; and if its point is sharp like an olive pit — forbidden, for behold it punctured it when it entered, and this is so the puncture not be seen because the mouth of the wound scabbed over. {Rama: And all the more if a needle or thorn is found in the gall bladder — treifah (Or Zarua, Ran, Rambam Hilchot Shechitah, Bach, Maharshal Piskei Avodah Zarah siman 49, and end of Sha'ar HaDin).}
