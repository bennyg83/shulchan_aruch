To peel — implies even not stuck need peel in roasting.
Stringency — Shach Torat Chatas: if did not peel and cooked — no concern; appears peel not needed after cooking unlike heart siman 72.
Itself — Shach: implies even if salted before forbidden; requires study — Rav Torat Chatas cites Rabbenu Yerucham not found opposite; Taz: practice rely liver cooked alone does not later forbid other foods by taste — itself not forbidden from law only stringency — without meat; with meat do not rely lenient; Peri Chadash disagrees.
Filling — Shach: only if heart/liver stuck to fowl; if not stuck filling joins nullify — unlike Maharshal; Rav implies if sixty filling also permitted though Maharshal and Bach disagree — many poskim eggs also "as it absorbs so it releases."
Eggs — Shach: if eggs even with unsalted meat — no "as it absorbs so it releases"; Taz siman 72: main Rama all egg filling like real cooking, helps where other meat helps nullify if not stuck in fowl; if stuck need sixty in fowl; stringent only forbid egg filling inside cavity alone even with sixty, not fowl — mere stringency suffices.
