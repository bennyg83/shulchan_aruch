For all the dead, if he wishes he tears by hand, if he wishes with a utensil; for father and mother by hand only; for all the dead if he comes to change within seven days he changes and does not tear; for father and mother if he changes within seven he tears all garments he changes and never mends like the first time. (For all the dead he may return the tear afterward within seven, but not for father and mother) (Rabbenu Yerucham in the name of Raavad).
