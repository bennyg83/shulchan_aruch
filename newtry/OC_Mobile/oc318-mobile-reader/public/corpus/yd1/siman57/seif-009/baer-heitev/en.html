To the pen. The Shach wrote: some acharonim — wide place only valley without fence; enclosed courtyard concerned; birds that slip away not concerned in wide courtyard only in coop — likewise Bach; permitted to sell even animal in enclosed wide courtyard since some acharonim lenient — safek in law; likewise Maharshal: in wide place even if one found derusah, not concerned for others — we say did not reach them; even for view enclosed courtyard not called wide — permitted to sell since some lenient — safek in law; other acharonim likewise.
Trembling. When both silent — perhaps accustomed to each other; when both trembling — each fears the other.
Its wrath. The Shach wrote: likewise if killed and did not cut — same law.
Wounded. (Likewise if trampled even without wound.) Shach wrote: implies even if it and they silent — all forbidden.
Others. Likewise if wounded others — one reason wrath did not subside — Shach wrote: implies whoever partly trampled — even if unknown it trampled after killing one — all forbidden; if killed two or more — dispute among poskim if wrath subsided; Taz lenient except chicken coop — be stringent in all cases.
