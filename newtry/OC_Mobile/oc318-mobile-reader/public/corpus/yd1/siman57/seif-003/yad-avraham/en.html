(Seif 10) In what case if cut one's head not concerned for others only when entered, etc.; but cats on full coop, etc., even cut head — wrath not subsided — Beit Yosef in Ran; Ra'ah Bedek HaBayit 45; Rashba Mishmeret HaBayit seems to disagree; we hold no difference rescuers; Gemara if cut head — wrath subsided; Semak/Tur no derisah only with rescuers — Gemara in this case; Orach Chaim and Darkei Moshe coop cat killed many — forbidden, no wrath subsided if killed more than one — Shach in Orach Chaim; Tzemach Tzedek 105 disagrees — if killed one and marks on others all forbidden; if killed first wrath not subsided; if not killed first trampled before subsided — others permitted; Shach/Orach Chaim if killed only one — wrath subsided even cat outside coop; Rashba/Semak/Orach Chaim — lenient sell to gentile per gloss s.s. this.
