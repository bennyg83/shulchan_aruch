(Seif 9 in gloss) And even if it killed one of them, etc. See Pei HaSadeh in Tzitz Eliezer: if one thrown dead — not like cutting head of one — died from derusah venom, all in safek derusah; I say if tear in belly from predator — cutting-head law; others permitted; if killed one and marks on others — all forbidden; if killed first — wrath not subsided; if not killed first — trampled before wrath subsided, others on presumption killed first — permitted except marked; Shach opposite; Pei HaSadeh; Tzemach Tzedek 105.
