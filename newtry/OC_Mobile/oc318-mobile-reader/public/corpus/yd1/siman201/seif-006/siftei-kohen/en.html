They must not, etc. therefore a barrel that was set in the ground and filled with rainwater, one does not immerse in it since the name of vessel was upon it before it was set ; end of Tur. And it implies that if the name of vessel was not upon it before it was set ; such as they set wood or stone and afterward carved it ; it is valid; and so in the mishnah and Asher"i and poskim, and Beit Yosef brings them.
