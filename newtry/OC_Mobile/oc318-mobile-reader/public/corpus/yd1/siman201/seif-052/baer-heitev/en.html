Like the mouth of a waterskin. Shach writes that this measure is required specifically when connecting a mikveh invalid by Torah law. If its invalidity is only rabbinic, an opening the width of a hair is sufficient, as stated below in seif 53.
In its validation. Rabbeinu Yerucham wrote commentators were uncertain if drawn remained in its validation or when hole sealed returns to invalid as initially; good to be stringent l'chatchila; Bach wrote not included in this validation if deficient mikveh mixed with complete since when hole sealed it is deficient before us — what helps it was mixed initially with complete; so Maharshal; so Rosh responsum; simple matters. Shach.
