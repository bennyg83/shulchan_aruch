And if the stream did not break, etc. One must say in Rama's words that if the stream did not break it is like iruy; and since the stream broke as above seif 7 and siman 98 seif 10 in the gloss, scraping suffices, for it is not considered iruy since the stream broke — so Terumat HaDeshen there.
For iruy only forbids kedei kelipah. Therefore even if there is food in the pot where kelipah remains, one need not peel — the pot is like kelipah; and so Maharshal there.
