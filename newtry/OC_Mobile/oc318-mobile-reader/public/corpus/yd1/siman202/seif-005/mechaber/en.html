A sickle whose handle broke from the lip inward is not a chatzitzah, because it is like an inner cavity. From the lip outward: if it is used in a manner similar to its work, it is not a chatzitzah; and if not, it is a chatzitzah. If it was wrapped in reeds or smeared with paste, this is a chatzitzah. If it is stuck with sap, it is not a chatzitzah.
