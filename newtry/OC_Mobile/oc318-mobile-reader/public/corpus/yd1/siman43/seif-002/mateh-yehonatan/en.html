(There Taz seif 2) I was asked in a district where calves found with perforation through and through, etc. What he wrote to permit because common in a district — one may say rabbeitehu; we wrote several times in name of Rashba's responsa we are not expert in rabbeitehu except if in entire that species this flaw exists — not if found in some without this flaw we do not say rabbeitehu. What he wants to permit because round hole created so is category deficiency kosher in spleen — prohibition only if punctured afterward — from Ramban's words appears opposite: Ramban wrote two spleens attached on thick side treifah; so Rama below hagahah seif 5 — because he holds all excess considered removed — that excess and its place with it and as if spleen punctured in hilum as Beit Yosef siman 41. If so in spleen since created so not like punctured spleen but created deficient and kosher — why did Ramban write if found like spleen on thick side treifah — even if we say like actual removal nevertheless only deficiency that does not treifah spleen at all — must say not like Taz who calls it hole if created so treifah; so when incident came before Avnei Nezer he did not fill his heart to be lenient in this case at all.
