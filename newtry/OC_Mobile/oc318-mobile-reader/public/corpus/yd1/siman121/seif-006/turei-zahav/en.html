Even sharp things like vinegar, etc. In Darkei Moshe it is written: I saw that some are lenient with vinegar to place it in a forbidden vessel, with proof from liver, for we say vinegar constricts it — so too it does not emit; and this is not so, for on the contrary in a vessel vinegar emits more, as written in Orach Chaim siman 442; and regarding liver it is different — so it seems to me; but through rinsing and washing it is certainly permitted, as Rashba wrote at the end of this siman regarding other sharp things.
