Fixed interest, etc. Here it is implied that we rule that a case involving only one possible side of interest is nevertheless fixed interest. Indeed, here there is only one possible side of interest, since it is possible that the matter will never result in interest. In siman 170 I wrote that on this point the Tur disagrees with R' Yehudah of Carcassonne. See Choshen Mishpat, siman 207, regarding when this condition that he return the field is effective, and the distinction stated there between a purchaser and a seller.
