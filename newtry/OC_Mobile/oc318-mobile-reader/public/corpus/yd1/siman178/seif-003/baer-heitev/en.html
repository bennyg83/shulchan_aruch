Bring. The Shach wrote: it implies that specifically bringing it there and placing it next to the pieces of bread is forbidden because of those who set a table for Gad; but if it was already there, he need not remove it. So too is implied from Rashi's explanation, and so it is written in Orach Chayim at the end of siman 180. With the bread pieces alone, there is a mitzvah to leave them so it will be ready for the poor person.
Prohibition. The Shach wrote: nevertheless, the practice in these lands of making a meal on the night before the infant is circumcised, called wach nacht, contains no prohibition. Only placing types of food on the table and leaving them that way is forbidden, because it is like setting a table for Gad; but with a meal there is no prohibition. The Taz wrote that in the Levush it is written that for this reason one should forbid the custom that some practice, to set the table on Shabbat nights with a whole loaf all night, which spread from the practice of those who set a table for Gad. But in my humble opinion this does not appear so. Specifically on the night before circumcision, when they do so for the infant's mazal, it has a connection to those who set for Gad, for gad is an expression of mazal; but on Shabbat nights, when they place the bread for lechem mishneh, it is for the honor of Shabbat, whose honor is with lechem mishneh, and there is no element of mazal in this and no prohibition at all. Indeed, even before Shabbat, immediately when they remove it from the oven, they place it on the table for the honor of Shabbat; end quote.
