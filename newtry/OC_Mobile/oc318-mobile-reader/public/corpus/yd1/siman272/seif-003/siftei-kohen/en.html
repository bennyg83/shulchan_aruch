Even one verse. Although the final verse does not contain words corresponding to the number of lines, he should make elongated letters from bottom to top so that one word occupies four or five lines, in order to finish at the end of the column. Tur. This implies that if there are many verses, he may write one word on each line according to the number of lines. However, all this is at the end of the Torah, since there is no other possibility; but in the middle of the Torah one should not do so, neither stretching letters lengthwise nor widthwise, but should write them according to their law, as below in siman 273. Nevertheless, if it happened that the scribe wrote this way, it is not invalidated thereby; so too it implies in Perishah.
