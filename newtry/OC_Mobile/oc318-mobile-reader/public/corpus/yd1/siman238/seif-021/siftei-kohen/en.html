The second oath does not, etc. See above, siman 239, seif 13, seif katan 27.
The second oath takes effect. For the sage uproots the vow retroactively, as though the first oath had never existed, and the second oath is therefore found to have taken effect from the outset. This implies that when a husband annuls a vow, which cuts it off only from that point onward and does not uproot it retroactively, even if he annuls the first vow the second does not take effect. Responsa Maharam Mintz, siman 40, writes likewise. See there.
