Regarding vows or oaths whether apply through agent — e.g. told agent vow or swear on my behalf whether applies to sender. Noda BiYehudah Makkot wrote not found explicit — implies we say agent like person — else wonder why condition in oath — condition requires act fulfillable through agent — if impossible through agent condition void; or can forbid through oath through agent. Beit Meir on Even HaEzer siman 120 challenged Noda BiYehudah — missed Ramban Bava Batra plainly nezirut not through agent yet condition applies; some distinguish condition Bava Batra and Bava Metzia only between person and fellow not between person and God — always condition; therefore vows and oaths not through agent; reason if because agent for opinion — Tosafot first chapter Bava Metzia wrote regarding agent for opinion agency void; or reason vow and oath not through agent because written your lips you shall keep and uttering lips — like commandment on body like laying tefillin not through agent; Hagahot Mordechai Ketubot — vow impossible through agent; answered there vow has condition from another reason — not need resemble Bava Batra and Bava Metzia only where act — unlike vow impossible speech alone voided by condition though impossible through agent — summary Beit Meir. Noda BiYehudah second edition Choshen Mishpat siman 247 noted himself Ramban and proved Tosafot first Nazir not through agent — seems main not Noda BiYehudah's son who brought proof against Tosafot and Ramban — proved exist through agent from Shevuot page 34 side 2 Rabbi Shimon finished oath deposit from trespass finished testimony — answer reasonable from trespass should learn deposit; if say told agent go swear on my behalf oath not apply to obligate sender in sacrifice — then one dispute oath deposit to trespass — trespass through agent obligates sender sacrifice — oath deposit not through agent obligate sender — still difficult Rabbi Shimon should learn deposit from testimony; or also oath prohibition through agent — end quote; in my humble opinion.
